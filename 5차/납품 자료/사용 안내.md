# 장기투자 모의운용 사용 안내

**현재 상태:** 5차 준비본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.


**이전 4차 설명 원문은 당시 상태이며 현재 상태가 아닙니다.** 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과는 입증되지 않았습니다.

## 5차 준비 상태

5차는 신규 관측별 제한 학습과 저장 전 검증을 구현한 변경본입니다. 실행 상태는 대시보드에서 확인하며 실제 GPU 추가 학습 완료와 독립 미래 성과·과적합 완전 방지는 입증되지 않았습니다. 기존 4차 안내는 이력으로 보존합니다.

5차 학습 반복은 고정 시험 구간을 호출하지 않습니다. 기존 `기준모델평가.json`·`최초시험평가.json`은 읽어서 보존하며 파일이 없으면 학습 중 새 시험 평가를 계산하거나 생성하지 않고 미측정으로 둡니다. 독립 시험은 학습 반복과 분리해야 하며 별도 시험 실행 도구는 현재 제공하지 않습니다.

| 조건 | 5차 방어 설계 |
| --- | --- |
| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
| 학습 설정 | 최대 25단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한값·표본 수 확인 |
| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |

새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다. 고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다. 세 ETF 기준은 전체 15종과 환율에 대한 독립 성과를 입증하지 않습니다. 미래 전진 평가는 별도로 유지합니다. 과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

## LEVEL 1 - Beginner

### LEVEL 1 · 5차 학습 방어

새 날짜가 있으면 전체 허용 과거 자료도 다시 표본으로 사용할 수 있습니다. 같은 관측 집합만으로 새 회차를 반복 예약하지 않으며, 무작위 표본이므로 모든 신규 행을 매회 학습한다는 보장은 없습니다.

ETF 가격은 날마다 쌓이는 기록이고 모델 가중치는 그 기록을 배운 결과를 저장한 값입니다. 같은 기록을 쉬지 않고 되풀이해 외우면 새로운 상황에 약해질 수 있습니다. 5차는 새로 배울 날짜가 없으면 학습을 기다리고 자료 수집과 가상 운용은 계속합니다.

예를 들어 새 날짜가 생기면 과거 자료도 다시 볼 수 있지만 같은 자료뿐인데 회차를 계속 시작하지 않도록 예약을 기록합니다. 새로 배운 뒤 기존 세 ETF의 정해진 확인 자료에서 오차가 나빠지면 운영 중인 저장값을 바꾸지 않습니다. 사용 전 실행 상태와 오류를 확인해야 하며 실제 돈으로 주문하지 않습니다.

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

5차 전환 후에는 5차 코드가 1차 실행 환경·가상 원장·마지막 Chronos-2 가중치를 이어 씁니다. 창을 닫는 것은 학습 중지가 아니므로 멈출 때는 운용 중지를 누릅니다. 원금은 가상 원화 100만 원이며 실제 계좌는 연결하지 않습니다. 수수료 기본 0.1%와 환전·SEC 비용 가정은 실제 토스 전체 비용과 다릅니다. 보유·거래·환전과 대기 상태를 따로 보고 체결이 없으면 0건으로 읽습니다. 학습을 계속해도 매번 매매할 필요는 없습니다.

### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

현재 최종 실행 파일은 3차 구성입니다. 5차 전환 후에만 `최종/대시보드 실행.cmd`를 실행하고 [대시보드](http://127.0.0.1:8879/)를 엽니다. 5차 준비본은 1차의 전용 실행 환경·모의 원장·마지막 Chronos-2 가중치를 이어 사용하도록 구성했습니다. 1차와 5차 폴더를 함께 보존하세요. 이전 2차 화면과 문서는 이력으로 남깁니다.

PC가 켜져 있고 학습 프로세스가 실행 중일 때 같은 모델을 계속 추가 학습합니다. 창을 닫는 것과 학습 중지는 다릅니다. 학습을 멈추려면 화면의 ‘운용 중지’를 누르세요. 전원 종료·절전·인터넷 중단 중에는 정상 운용을 보장하지 않습니다.

학습 감시 프로세스는 확인된 치명 CUDA 오류가 발생하면 마지막 저장 가중치로 새 학습 프로세스를 실행합니다. 화면에 복구 대기와 재실행 상태를 표시하고, 사용자 중지 뒤에는 재시작하지 않습니다. 전원 종료나 모든 종류의 하드웨어 오류까지 자동 복구하는 기능은 아닙니다.

모의 원금은 원화 100만 원입니다. 달러로 환전한 기존 현금과 환전 기록을 그대로 사용합니다. 사용자의 실제 보유와 토스 계좌는 연결하지 않습니다. 기본 매매 수수료 0.1%, 공개 기본 환전·SEC 비용 가정이며 실제 토스의 호가·환율·배당 지급일·세금·결제 전체와 같지는 않습니다. 비용 정책은 2027년 전환 전에 다시 확인해야 합니다.

‘보유·거래’에서 현재 보유 종목·수량·평균 매입가·원화 원가·평가·손익을 확인합니다. 주문 대기와 실제 모의 체결을 구분하며 환전은 별도 표에 표시합니다. ETF 거래내역은 매수·매도 필터와 페이지 이동으로 전체 기록을 읽습니다. 아직 체결이 없으면 보유와 거래는 0건으로 표시됩니다.

자동 매매 후보는 QQQM·SCHG·SPYM·VTI·VEA·VWO·BND·IEF·TLT·SGOV·GLD·XLK·XLF·XLV·XLE입니다. 모델 예측·비용·현금 제약으로 선택합니다. 모든 상장 ETF 또는 토스 지원 전 종목을 검증한 목록은 아닙니다. 차입·공매도·레버리지 ETF는 사용하지 않습니다. 학습을 계속해도 매번 거래할 필요는 없습니다.

학습 자료는 무료 완결 일봉입니다. 실제 운용의 모의 체결에는 주문 뒤 시작한 정규장 완결 1분봉을 사용하며 최대 20분 지연을 허용합니다. 현재 정규장이어야 하고 시세가 없거나 오래됐으면 개별 주문을 대기합니다. 과거 시가로 소급 체결하지 않습니다. 화면의 1초 상태 확인은 무료 초 단위 실시간 시세를 뜻하지 않습니다.

백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율과 전체 정밀도는 원값 보기에서 확인합니다. 원값 스냅샷은 직접 갱신하고 저장 결과는 바꾸지 않습니다. 반올림된 100.0%와 실제 원비율 1을 구분합니다. 과거 비교 수익과 가정 시나리오는 현재 모의계좌 수익과 다릅니다. 수익 우위나 실거래 검증 완료를 의미하지 않습니다.

키보드 메뉴·버튼·입력 이동, 표 가로 스크롤, 다크·라이트와 화면 모션 정지·재생을 제공합니다. 전체 마우스 오버·200% 확대·운영체제 모션 축소·전체 터치 조합은 미검증 범위입니다.

### LEVEL 2 · 구성과 조건의 관계

1차의 환경·저장 상태와 5차 화면·엔진을 연결하는 사용 안내입니다. 후보 15종의 선택은 예측·비용·현금 제약을 따르며 차입·공매도·레버리지 ETF를 사용하지 않습니다. 학습 입력인 완결 일봉과 체결 입력인 주문 뒤 정규장 완결 1분봉·최대 20분을 구분합니다. 1초 상태 조회를 초 단위 실시간 시세로 해석하지 않습니다. 치명 CUDA 복구도 사용자 중지·전원·절전·인터넷 장애와 경계가 다릅니다.

### LEVEL 2 · 이 자료의 세부 조건을 함께 읽기

기존 평가 세 ETF는 고정 조정값을 우선합니다. 환율은 독립 단변량 학습이며 ETF 공변량이나 인과 학습이 아닙니다. 2020년 이전 누락 이력과 제공되는 2000년 이전 이력도 수집 대상이나 실제 제공 범위와 학습에 적합한 길이는 자산별 실행 결과로 확인합니다. 기존 모델의 마지막 가중치를 이어 쓰며 4차 성과는 미측정입니다.



### LEVEL 4 · 설계·평가·실패 경계

최종 사용 경계는 기존 환경/원장/가중치 계승, 사용자 중지와 치명 CUDA 재기동, 일봉 학습과 시간 제한 모의체결의 분리입니다. 15후보는 모든 상장 ETF/토스 전 종목 검증이 아니고 0.1%·환전·SEC는 공개 기본 가정입니다. 실제 계좌·호가·배당·세금·결제의 완전 재현이나 수익 우위를 주장하지 않습니다. 원값 불변성·수동 스냅샷과 표시 반올림, 조작별 실제 검증 범위를 함께 검토합니다.

### LEVEL 4 · 이 자료의 세부 조건을 함께 읽기

현재 최종 실행 파일은 3차 구성입니다. 5차 전환 후에만 `최종/대시보드 실행.cmd`를 실행하고 [대시보드](http://127.0.0.1:8879/)를 엽니다. 5차 준비본은 1차의 전용 실행 환경·모의 원장·마지막 Chronos-2 가중치를 이어 사용하도록 구성했습니다. 1차와 5차 폴더를 함께 보존하세요. 이전 2차 화면과 문서는 이력으로 남깁니다.

PC가 켜져 있고 학습 프로세스가 실행 중일 때 같은 모델을 계속 추가 학습합니다. 창을 닫는 것과 학습 중지는 다릅니다. 학습을 멈추려면 화면의 ‘운용 중지’를 누르세요. 전원 종료·절전·인터넷 중단 중에는 정상 운용을 보장하지 않습니다.

학습 감시 프로세스는 확인된 치명 CUDA 오류가 발생하면 마지막 저장 가중치로 새 학습 프로세스를 실행합니다. 화면에 복구 대기와 재실행 상태를 표시하고, 사용자 중지 뒤에는 재시작하지 않습니다. 전원 종료나 모든 종류의 하드웨어 오류까지 자동 복구하는 기능은 아닙니다.

모의 원금은 원화 100만 원입니다. 달러로 환전한 기존 현금과 환전 기록을 그대로 사용합니다. 사용자의 실제 보유와 토스 계좌는 연결하지 않습니다. 기본 매매 수수료 0.1%, 공개 기본 환전·SEC 비용 가정이며 실제 토스의 호가·환율·배당 지급일·세금·결제 전체와 같지는 않습니다. 비용 정책은 2027년 전환 전에 다시 확인해야 합니다.

‘보유·거래’에서 현재 보유 종목·수량·평균 매입가·원화 원가·평가·손익을 확인합니다. 주문 대기와 실제 모의 체결을 구분하며 환전은 별도 표에 표시합니다. ETF 거래내역은 매수·매도 필터와 페이지 이동으로 전체 기록을 읽습니다. 아직 체결이 없으면 보유와 거래는 0건으로 표시됩니다.

자동 매매 후보는 QQQM·SCHG·SPYM·VTI·VEA·VWO·BND·IEF·TLT·SGOV·GLD·XLK·XLF·XLV·XLE입니다. 모델 예측·비용·현금 제약으로 선택합니다. 모든 상장 ETF 또는 토스 지원 전 종목을 검증한 목록은 아닙니다. 차입·공매도·레버리지 ETF는 사용하지 않습니다. 학습을 계속해도 매번 거래할 필요는 없습니다.

학습 자료는 무료 완결 일봉입니다. 실제 운용의 모의 체결에는 주문 뒤 시작한 정규장 완결 1분봉을 사용하며 최대 20분 지연을 허용합니다. 현재 정규장이어야 하고 시세가 없거나 오래됐으면 개별 주문을 대기합니다. 과거 시가로 소급 체결하지 않습니다. 화면의 1초 상태 확인은 무료 초 단위 실시간 시세를 뜻하지 않습니다.

백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율과 전체 정밀도는 원값 보기에서 확인합니다. 원값 스냅샷은 직접 갱신하고 저장 결과는 바꾸지 않습니다. 반올림된 100.0%와 실제 원비율 1을 구분합니다. 과거 비교 수익과 가정 시나리오는 현재 모의계좌 수익과 다릅니다. 수익 우위나 실거래 검증 완료를 의미하지 않습니다.

키보드 메뉴·버튼·입력 이동, 표 가로 스크롤, 다크·라이트와 화면 모션 정지·재생을 제공합니다. 전체 마우스 오버·200% 확대·운영체제 모션 축소·전체 터치 조합은 미검증 범위입니다.

## LEVEL 5 - Expert

### LEVEL 5 · 5차 학습 방어

새 날짜가 있으면 전체 허용 과거 자료도 다시 표본으로 사용할 수 있습니다. 같은 관측 집합만으로 새 회차를 반복 예약하지 않으며, 무작위 표본이므로 모든 신규 행을 매회 학습한다는 보장은 없습니다.

검증은 최초 세 ETF의 고정 검증 자료에 대한 학습 전후 MAE·MAPE 비교이며 표본 수가 양수이고 값이 유한해야 합니다. 두 지표 모두 악화 허용치는 0입니다. 같은 고정 구간을 반복해 사용하므로 결과는 새로운 독립 시험이 아닙니다. 확장 15종목이나 FX 각각의 일반화와 미래 수익을 입증하지 않습니다.

초기 20단계 시험은 각 144관측에서 추가 학습 MAPE 약 0.7643%, 무변화 예측 약 0.7550%였고 각 요약은 0.8%입니다. 이는 5차 방어의 효과가 아닙니다. 실제 예약 원장·학습 설정·검증 분모·발행 전 실패 시 운영 포인터와 신호 차단을 최종 구현과 검사 근거에서 검토해야 합니다.

# 5차·과적합 위험을 줄이는 추가 학습

현재 상태: 5차 준비 본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.


5차는 신규 관측 별 제한 학습과 저장 전 검증을 구현한 변경 본입니다. 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과·과적합 완전 방지는 입증되지 않았습니다. 같은 모델을 이어 사용하며 새 관측이 없으면 학습을 기다리고 수집과 모의 운용을 유지하는 방어를 구현했습니다.

[5차 상세](docs/5차%20상세.md) · [직전 전체 비교](docs/5차%20전체%20비교.md) · [사용 안내](사용%20안내.md)

| 조건 | 5차 방어 설계 |
| --- | --- |
| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
| 학습 설정 | 최대 25 단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한 값·표본 수 확인 |
| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |

새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다.

고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다.

세 ETF 기준은 전체 15 종과 환율에 대한 독립 성과를 입증하지 않습니다.

미래 전진 평가는 별도로 유지합니다.

과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

## 4차 기록

# 4차·전체 제공 이력과 이어 학습

이전 4차 설명 원문은 당시 상태이며 현재 상태가 아닙니다. 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과는 입증되지 않았습니다.

기존 Chronos-2 마지막 가중치와 모의 원장을 이어 사용하며 15개 ETF와 환율의 수집 가능한 전체 일봉을 학습 자료로 확보합니다.

[상세 설명](docs/4차%20상세.md) · [직전 전체 비교](docs/4차%20전체%20비교.md) · [사용 안내](사용%20안내.md)

| 항목 | 4차의 범위 |
| --- | --- |
| 입력 | 15개 ETF와 KRW=X의 수집 가능한 전체 일봉 |
| 과거 학습 | 자산별 2024-06-03 이하 |
| 고정 검증 | 2024-06-04~2025-08-21, 모든 자산 학습에서 제외 |
| 고정 시험 | 2025-08-22~2026-11-06, 모든 자산 학습에서 제외 |
| 이후 학습 | 2026-11-06 초과, 과거 구간과 별도 시계열 |
| 모델·계좌 | 기존 Chronos-2 마지막 가중치와 가상 원금 100 만 원 원장 유지 |

전체 제공 이력을 요청해 2020년 이전에 빠진 ETF 이력과 제공되는 2000년 이전 이력도 포함합니다.

실제 제공 기간과 수집 가능 여부는 종목마다 다릅니다.

기존 평가의 세 ETF는 고정된 조정 가격 원본을 우선 합니다.

KRW=X는 독립 단변량 학습이며 ETF 공변량 또는 인과 학습이 아닙니다.

학습 허용 구간을 분리해 평가 구간을 가로지르지 않습니다.

짧은 시계열의 학습 가능 여부는 실제 실행 결과로 확인해야 합니다.

실제 주문은 전송하지 않습니다. 수집과 학습의 반복은 독립 표본 수나 투자 수익 우위를 뜻하지 않습니다. 4차 성과는 아직 측정되지 않았습니다. [사용 안내](사용%20안내.md) · [전체 비교](docs/4차%20전체%20비교.md)

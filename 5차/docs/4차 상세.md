# 4차 상세·전체 제공 이력과 이어 학습

**4차는 준비 본입니다.** 전체 이력 수집과 학습 입력 구성·코드 검사는 마쳤지만, 4차의 실제 모델 추가 학습과 운용 전환은 검증하지 못했습니다. 현재 연속 운용과 최종 실행 파일은 기존 3차를 유지합니다. 아래 4차 학습 설명은 구현된 준비 본의 동작이며 실행 완료나 성능 향상을 뜻하지 않습니다.

## LEVEL 1 - Beginner

ETF는 여러 자산을 묶어 거래하는 상품이고 일봉은 하루의 가격 기록입니다. 더 오래된 기록과 새 기록을 사용하되 중간에 남겨 둔 시험 기간은 공부 자료에 넣지 않습니다.

### 처음 사용할 때

모델의 **가중치**는 앞서 배운 내용을 저장한 값입니다. 4차는 새 모델을 골라 교체하는 대신 마지막 저장 값에서 계속 배웁니다.

예를 들어 한 ETF에 오래된 가격과 최근 가격이 있어도 가운데 검증·시험 기간은 학습에서 빼고 양쪽을 따로 다룹니다.

환율은 원화와 달러의 교환 비율로, ETF를 설명하는 입력으로 묶지 않고 별도로 학습합니다.

기존 1차 실행 환경과 가상 원장을 보존하고 4차 사용 안내의 시작 파일을 엽니다. 화면에서 학습 상태와 보유·대기 주문·모의 체결을 각각 확인합니다. 가격이 없으면 기다릴 수 있으며 학습했다고 반드시 매매하거나 수익이 난다는 뜻은 아닙니다. 창을 닫는 것과 운용 중지는 다릅니다.

| 항목 | 4차의 범위 |
| --- | --- |
| 입력 | 15개 ETF와 KRW=X의 수집 가능한 전체 일봉 |
| 과거 학습 | 자산별 2024-06-03 이하 |
| 고정 검증 | 2024-06-04~2025-08-21, 모든 자산 학습에서 제외 |
| 고정 시험 | 2025-08-22~2026-11-06, 모든 자산 학습에서 제외 |
| 이후 학습 | 2026-11-06 초과, 과거 구간과 별도 시계열 |
| 모델·계좌 | 기존 Chronos-2 마지막 가중치와 가상 원금 100 만 원 원장 유지 |

전체 제공 이력을 요청해 2020년 이전에 빠진 ETF 이력과 제공되는 2000년 이전 이력도 포함합니다.

실제 제공 기간과 수집 가능 여부는 종목마다 다릅니다.

기존 평가의 세 ETF는 고정된 조정 가격 원본을 우선 합니다.

KRW=X는 독립 단변량 학습이며 ETF 공변량 또는 인과 학습이 아닙니다.

학습 허용 구간을 분리해 평가 구간을 가로지르지 않습니다.

짧은 시계열의 학습 가능 여부는 실제 실행 결과로 확인해야 합니다.

실제 주문은 전송하지 않습니다. 수집과 학습의 반복은 독립 표본 수나 투자 수익 우위를 뜻하지 않습니다. 4차 성과는 아직 측정되지 않았습니다. [사용 안내](../사용%20안내.md) · [전체 비교](4차%20전체%20비교.md)

## LEVEL 5 - Expert

자산별 날짜 경계·가격 출처·시계열 분리와 평가 누수 방지를 코드 및 실제 데이터로 대조합니다. 사전 학습 데이터 경계는 확인되지 않았고 4차 성과는 미측정입니다.

### 프로토콜과 재현 검토

고정 검증과 시험 날짜는 모든 자산에 적용합니다.

동일 날짜가 다른 자산을 통해 학습에 들어오거나 두 학습 구간이 한 창으로 연결되는지 검토해야 합니다.

세 ETF의 보존된 평가 원본과 조정 가격 우선순위, 수집 원본과 학습 입력 스냅샷을 대조합니다. `src/training_data.py`의 구간별 적합 여부와 관측 수, `src/modeling.py`의 실행 명세·체크포인트를 확인합니다.

기존 초기 20 단계 시험은 각 144 관 측에서 추가 학습 MAPE 약 0.7643%, 무변화 예측 약 0.7550%였고 한 자리 요약은 둘 다 0.8%입니다.

이는 4차의 실측 성과가 아니며 수익 우위를 뒷받침하지 않습니다.

자산별 실제 수집 분모·시작 일과 사전 학습 자료의 자산·시점 경계는 확인 결과에 따라 별도로 기술해야 합니다.

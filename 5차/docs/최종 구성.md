# 5차 전환 계획·현재 최종 3차 유지

**현재 상태:** 5차 준비 본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.


**5차는 신규 관측 별 제한 학습과 저장 전 검증을 구현한 변경 본입니다.** 실행 상태는 대시보드에서 확인하며 GPU 추가 학습 완료와 독립 미래 성과·과적합 완전 방지는 입증되지 않았습니다. 최종 실행 파일은 현재 3차를 유지하며 5차 전환은 완료되지 않았습니다.

기존 시험 평가 파일이 없더라도 학습 결정에 사용하지 않으며 학습 중 시험 평가를 새로 만들지 않습니다. 별도 시험 실행 도구는 현재 제공하지 않아 독립 미래 성과는 입증되지 않았습니다.

| 항목 | 대상 |
| --- | --- |
| 소스 | 5차 프로그램 |
| 최종 실행 파일 | 현재 3차 유지, 5차 전환은 미완료 |
| 환경·모의 원장·가중치 | 기존 1차 비공개 저장소 사용 |
| 학습 방어 | 새 적합 날짜별 제한 학습과 고정 검증 후 반영 |

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

최종 실행 파일은 현재 3차를 유지합니다. 5차로 변경하려면 별도 전환이 필요합니다. 기존 1차의 가상 돈 기록과 모델 저장 값을 이어 씁니다. 새 날짜가 없으면 학습을 쉬고 자료 수집과 가상 운용을 계속합니다.

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer

시작 파일은 5차 서버를 가리키며 서버는 1차 실행 환경과 비공개 저장 상태를 사용하도록 구성합니다. 신규 날짜 예약과 검증 전후 오차 판정은 학습 결과의 운영 반영을 제어합니다.

[5차 같은 수준](5차%20상세.md#reading-level-2) · [프로젝트 같은 수준](../../docs/읽기안내/레벨2.md) · [직전 전체 비교](5차%20전체%20비교.md)

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner

실행 파일과 사용 안내를 최종 폴더에 두기 전에 단위 검사와 독립 검토를 완료하고, 실행 대상과 1차 환경·원장 연결을 확인합니다. 실제 실행 상태는 대시보드에서 확인하며 GPU 추가 학습 완료는 입증되지 않았습니다.

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced

최종 시작 파일, 5차 소스, 1차 환경·원장·체크포인트는 별도 경계입니다. 포인터 발행 전 STOP·검증 실패·오류를 관측하면 기존 운영 포인터가 유지되고 새 가중치의 주문 전망이 미발행되는지 실제 구현과 확인 결과를 대조합니다.

<a id="reading-level-5"></a>
## LEVEL 5 - Expert

시작 파일 경로와 실제 프로세스의 코드·환경·원장을 확인하고 예약 영속성, 세 ETF 고정 검증의 MAE·MAPE·유한성·분모 및 실패 시 반영 차단을 검토합니다. GPU 추가 학습 완료와 독립 미래 투자 성과는 입증되지 않았습니다.

[5차 같은 수준](5차%20상세.md#reading-level-5) · [프로젝트 같은 수준](../../docs/읽기안내/레벨5.md) · [직전 전체 비교](5차%20전체%20비교.md)

새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

포인터 발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증 후 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 원자 저장 자체가 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

기존 최종 파일은 차수별 보존 자료와 대조하고 교체 전 복구본과 무결성을 확인합니다. 수익 보장이나 과적합 완전 방지는 뜻하지 않습니다.

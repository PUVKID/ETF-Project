# 변경 기록

**현재 상태:** 5차 준비 본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.


## 5차·과적합 위험 방어 준비

신규 적합 날짜별 제한 학습, 영속 예약, 세 ETF 고정 검증의 MAE·MAPE와 유한 값 검사 및 운영 가중치 보호를 구현합니다.

최대 25 단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0입니다.

새 날짜가 없을 때 수집·모의 운용은 계속합니다. 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과는 입증되지 않았습니다. [전체 비교](docs/5차%20전체%20비교.md)


새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

## 4차·전체 제공 이력

15개 ETF와 KRW=X의 수집 가능한 전체 일봉을 요청합니다.

기존 평가 원본의 조정 값을 우선 하고 검증·시험 기간을 모든 자산 학습에서 제외하며, 2024-06-03 이하와 2026-11-06초과를 분리합니다.

환율은 독립 단 변 량으로 학습합니다.

같은 모델의 마지막 가중치와 모의 원장을 이어 사용합니다.

실제 수집 범위와 추가 학습 성과는 실행 결과로 확인해야 합니다. [전체 비교](docs/4차%20전체%20비교.md)


## 3차·2026-11-10

현재 보유, 주문 상태, 전체 ETF 체결 내역, 환전을 구분해 표시하고 체결 내역 페이지·방향 필터를 추가했습니다. 자동 후보는 기존 세 종목에서 주식·채권·금·업종을 포함한 15개로 넓혔습니다. 전진 체결에는 주문 뒤 정규 장 완결 1분봉의 시간·지연·현금 제약을 적용합니다.

기존 모의 원금과 원장·가중치·고정 시험 자료를 보존하고 신규 후보 학습 자료와 정책 버전을 분리합니다. 백분율 요약은 최신 표시 기준에 따라 소수 첫째 자리 반올림으로 바꾸며 전체 원값은 유지합니다.

치명적인 CUDA 실행 실패는 손상된 문맥 안에서 계속 재시도하지 않고, 감시 프로세스가 마지막 저장 가중치로 새 학습 프로세스를 실행하도록 보완했습니다.

중지 요청이 있으면 재실행하지 않으며 감시 잠금으로 중복 실행을 막습니다.

예측 계산 중 중지가 들어온 경우 새 신호와 계좌 재조정을 발행하지 않는 경계도 추가했습니다.

최초 장치 오류의 하드웨어 원인을 확정한 것은 아닙니다.

실제 추가·수정·삭제 파일, 사소한 공백·주석 변경, 바이너리 크기·해시는 [전체 비교](docs/3차%20전체%20비교.md)에 기록합니다. 모델·데이터·계좌·운영/검증 기록은 비공개입니다. 검사 성공은 투자 수익 우위 또는 실거래 검증 완료를 의미하지 않습니다.

이전 차수: [1차](../1차/변경기록.md) · [2차](../2차/변경기록.md)


운영 전환과 4차 실제 추가 학습은 검증하지 못했습니다. 기존 3차 연속 운용을 재개하고 최종 납품 본은 유지합니다. 전체 이력 수집과 코드·자료 구성 검사 결과를 실제 모델 학습 성공으로 표시하지 않습니다.

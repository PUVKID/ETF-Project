## 실행과 중지

현재 서버가 실행 중이면 위 주소를 여세요. 서버가 꺼진 경우 `최종/대시보드 실행.cmd`를 실행합니다. 실제 프로그램과 전용 Python 환경은 같은 프로젝트의 `1차`에 있으므로 폴더 이름과 위치를 유지해 주세요. 이미 켜진 서버를 중복 실행하지 않습니다.

화면의 **계속 운용 시작**은 자료 확인 → 마지막 가중치의 추가 학습 → 검증 기록 → 모의계좌 반영을 반복합니다. 정상 회차 사이에 정해진 휴식은 없습니다. 무료 시세는 6시간 캐시를 사용하며 화면은 1초마다 상태를 확인합니다. 새 일봉이 없는 날에도 기존 학습 자료로 학습하고, 새 가격이 없으면 가상 체결을 만들지 않습니다.

**운용 중지**를 누르면 학습 단계가 끝나는 지점에서 중지를 확인하고 가능한 현재 가중치를 저장합니다. 라이브러리 초기 읽기·모델 읽기·검증 중에는 버튼 반응 뒤 실제 종료까지 시간이 걸릴 수 있습니다. 중지 후 **계속 운용 시작**으로 마지막 저장 가중치에서 다시 시작합니다. 컴퓨터를 끄거나 프로세스를 종료하면 운용도 중단되며, 재부팅 뒤 자동 실행은 설정하지 않았습니다.

## 원금과 비용

가상 원금은 **1,000,000원**입니다. 시장 USD/KRW 환율과 환전 스프레드로 달러로 바꾼 뒤 QQQM·SCHG·SPYM을 소수점 매매하며, 평가금액·손익·비용을 원화로 표시합니다. 기존 실제 계좌 보유 내역과 추가 입금은 사용하지 않습니다.

일반 매매 수수료 0.1%, 주문 총액 10달러 이하 매매 수수료 면제, 센트 미만 절사, 매도 SEC 비용을 적용합니다. 환전은 국내 영업일이 확인된 09:00~15:30에 5bp, 그 외 또는 영업일 미확인에는 50bp를 적용합니다. 최초 야간 환전은 50bp입니다. 2026-12-31 이후 규제 비용 정책은 다시 확인해야 합니다.

무료 일봉 환율·시가는 토스의 실제 은행 환율·호가·체결 내역과 다릅니다. 배당은 실제 지급일 대신 일봉 배당 관측일에 현금으로 반영하며, 배당 원천징수·연간 양도소득세·예탁금 이자·결제일·부분 체결은 재현하지 않습니다. 화면의 모의 손익은 세후 실거래 손익이 아닙니다. 토스 계좌 인증과 실거래 주문 기능은 연결하지 않았습니다.

## 학습 결과 해석

`amazon/chronos-2` 하나의 마지막 저장 가중치를 계속 갱신합니다. 후보 모델 경쟁이나 채택 절차는 없으며, 회차마다 최적화기 상태는 새로 생성합니다. 추가 학습으로 모델 구조와 매개변수 수가 자동 증가하지 않습니다.

첫 20단계 학습은 저장까지 확인했습니다. 초기 시험 구간의 MAPE는 추가 학습 모델 약 0.7643%, 무변화 예측 약 0.7550%로, 초기 학습의 우위가 확인된 결과는 아닙니다. 반복 학습·낮은 손실·짧은 모의투자 기간만으로 10년 수익을 입증할 수 없습니다. 과거 정책 비교와 운용 시작 뒤의 모의 원장은 별개입니다.

가중치·시세·모의 원장·실패 기록은 `1차/work/비공개`에 저장합니다. 오류가 발생하면 화면에 표시하고 재시도하며, 무결성 검사를 통과하지 못한 가중치를 최신 저장본으로 바꾸지 않습니다. 이 폴더와 `.venv`는 실행에 필요하므로 삭제하지 마세요.

모든 미래 결함이 없거나 실거래 수익을 보장하는 완성품이라는 의미는 아닙니다. 장기간 운용 중 데이터 제공 정책·규제 비용·환경 상태를 확인해야 합니다.

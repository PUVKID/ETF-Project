# 변경 기록

## 1차

신규 장기투자 모의운용 프로젝트를 구성합니다. 이전 기준 커밋이 없는 첫 차수이므로 기존 파일 대비 수정·삭제로 설명하지 않습니다.

공개 범위는 프로그램 코드와 일반 문서이며 개인 보유 내역, 키, 시세 원본·가중치·운영 기록과 개인 지침은 제외합니다. 실제 추가 파일 목록과 크기·SHA-256은 전체 비교 자료로 연결합니다.

무료 완결 일봉 11,040행과 실제 USD/KRW 일봉 환율을 수집했습니다. Chronos-2 최초 20단계 학습·저장과 다음 회차에서 누적 단계가 늘어나는 이어 학습을 실제 확인했습니다. 모델 경쟁·채택 관문은 사용하지 않습니다. 초기 시험 수치는 투자 우위가 확인된 결과가 아닙니다.

원금 100만원을 달러로 환전한 모의 원장과 원화 평가를 연결했습니다. 토스 일반 매매 0.1%, 소액 주문 면제, 센트 절사, 매도 SEC 반올림, 시간대별 환전 스프레드를 적용합니다. 실제 신호 생성 뒤의 새 시가만 체결하며 소급·중복 체결을 방지합니다. 실제 체결 호가·세후 손익 재현은 범위 밖입니다.

실행 중 Windows 잠금 byte를 읽어 API 조회가 실패했던 문제를 수정하고 회귀 검사를 추가했습니다. 상태 전체 저장을 최대 초당 1회로 제한하고 손실·저장 텐서의 유한값 검사를 유지했습니다. 원화 환산 MAE와 명시적 통화 단위, 라이브러리 불러오기 상태도 표시합니다. 과거 실패 원문은 로컬 비공개 이력에 보존합니다.

핵심 단위검사 24개와 화면 문법 검사를 구현자 및 별도 검토자가 통과했습니다. 실제 중지·저장·재개 최종 검토와 GitHub 원격 확인 결과는 각각 별도 기록합니다. 저장소 생성 기능·브라우저 인증/접근 제약으로 원격 반영은 대기 중이며 전체 공개 완료로 보고하지 않습니다.

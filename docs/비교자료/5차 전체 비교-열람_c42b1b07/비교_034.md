++## 이어 학습과 성과 해석
++
++`amazon/chronos-2`의 같은 마지막 가중치를 계속 갱신합니다. 회차마다 모델을 경쟁시키거나 채택하지 않습니다. 3차에서는 최초 세 ETF의 고정 학습·검증·시험 구간과 기준 평가를 보존하고 신규 ETF의 과거 학습을 원래 학습 종료일 이하로 제한했습니다. 4차의 학습 범위는 위 표를 따릅니다. 최초 시험 종료 뒤 새 자료는 추가 학습이며 독립 시험 성과가 아닙니다.
++
++약 두 달 학습은 운용 계획입니다. PC와 로컬 프로세스 실행 중 반복하며 전원·절전·인터넷·프로세스 중단의 영향을 받습니다. 같은 표본의 반복 횟수와 독립 원본 수를 구분합니다.
++
++초기 20단계 시험 MAPE 원값은 추가 학습 약 0.7643%, 무변화 예측 약 0.7550%였으며 요약은 각각 0.8%, 0.8%입니다. 투자 수익 우위가 입증된 결과는 아닙니다.
++
++과거 모의 비교, 운용 후 쌓이는 전진 기록, 가정 수익률 시나리오는 다릅니다. 사전학습 데이터의 개별 자산·시점 경계는 확인되지 않았습니다. 10년은 계획 기간이며 짧은 ETF 이력을 10년 실측 성과로 만들지 않습니다. 수익·원금 보존·실거래 성능을 보장하지 않습니다.

+# 5차 상세 · 과적합 위험을 줄이는 추가 학습
+
+**현재 상태:** 5차 준비본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.
+
+
+**5차는 신규 관측별 제한 학습과 저장 전 검증을 구현한 변경본입니다.** 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과·과적합 완전 방지는 입증되지 않았습니다.
+
+<a id="reading-level-1"></a>
+## LEVEL 1 - Beginner
+
+ETF 가격은 날마다 쌓이는 기록이고 모델 가중치는 그 기록을 배운 결과를 저장한 값입니다. 같은 기록을 쉬지 않고 되풀이해 외우면 새로운 상황에 약해질 수 있습니다. 5차는 새로 배울 날짜가 없으면 학습을 기다리고 자료 수집과 가상 운용은 계속합니다.
+
+예를 들어 새 날짜가 생기면 과거 자료도 다시 볼 수 있지만 같은 자료뿐인데 회차를 계속 시작하지 않도록 예약을 기록합니다. 새로 배운 뒤 기존 세 ETF의 정해진 확인 자료에서 오차가 나빠지면 운영 중인 저장값을 바꾸지 않습니다. 사용 전 실행 상태와 오류를 확인해야 하며 실제 돈으로 주문하지 않습니다.
+
+5차 학습 반복은 고정 시험 구간을 호출하지 않습니다. 기존 `기준모델평가.json`·`최초시험평가.json`은 읽어서 보존하며 파일이 없으면 학습 중 새 시험 평가를 계산하거나 생성하지 않고 미측정으로 둡니다. 독립 시험은 학습 반복과 분리해야 하며 별도 시험 실행 도구는 현재 제공하지 않습니다.

+
+발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.
+
+이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다. 고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다. 세 ETF 기준은 전체 15종과 환율에 대한 독립 성과를 입증하지 않습니다. 미래 전진 평가는 별도로 유지합니다. 과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

+## LEVEL 3 - Practitioner
+
+기존 1차의 실행 환경·모의 원장·가중치와 1~4차 자료를 보존합니다. 5차 적용 전에는 독립 검토와 실패 경로 검증이 필요합니다. 화면에서 수집 및 대기 상태, 학습 예약·결과와 오류를 확인하고 운용을 멈출 때는 운용 중지를 사용합니다.
+
+최초 1회 이후에는 새 적합 날짜가 있어야 학습하며 실행마다 최대 25단계입니다. 포인터 발행 전 검증 오차 악화·유효 표본 부재·비유한 수치·STOP·오류를 관측할 때 기존 운영 포인터가 유지되는지와 새 가중치 주문 전망이 발행되지 않는지 확인합니다. 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과는 입증되지 않았습니다.
+
+5차 학습 반복은 고정 시험 구간을 호출하지 않습니다. 기존 `기준모델평가.json`·`최초시험평가.json`은 읽어서 보존하며 파일이 없으면 학습 중 새 시험 평가를 계산하거나 생성하지 않고 미측정으로 둡니다. 독립 시험은 학습 반복과 분리해야 하며 별도 시험 실행 도구는 현재 제공하지 않습니다.
+
+| 조건 | 5차 방어 설계 |
+| --- | --- |
+| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
+| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
+| 학습 설정 | 최대 25단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
+| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한값·표본 수 확인 |
+| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
+| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |
+
+새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.
+
+발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.
+
+이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다. 고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다. 세 ETF 기준은 전체 15종과 환율에 대한 독립 성과를 입증하지 않습니다. 미래 전진 평가는 별도로 유지합니다. 과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

+## LEVEL 4 - Advanced
+

+

+## LEVEL 5 - Expert
+

+                return

+def select_allocation(forecasts, equity_usd, policy=None):
+    policy = {**DEFAULT_POLICY, **(policy or {})}

+    cost = 0.002 + 0.01 / budget

+        symbol = row["symbol"]
+        predicted, previous = float(row["adjusted_price"]), float(row["last_adjusted_price"])
+        if symbol not in SYMBOLS or not all(math.isfinite(v) and v > 0 for v in (predicted, previous)):

+def quote_waiting_reason(quote, created_at, current, max_age=1200):
+    if quote is None:
+        return "해당 ETF의 무료 단기 시세를 확보하지 못했습니다"
+    try:
+        now, created = timestamp(current), timestamp(created_at)
+        start, end, fetched = (timestamp(quote[k]) for k in ("bar_start", "bar_end", "fetched_at"))
+        opening, closing = timestamp(quote["session_open"]), timestamp(quote["session_close"])
+        if not math.isfinite(float(quote["price"])) or quote["price"] <= 0:
+            return "유효한 양의 관측 가격이 없습니다"
+        if quote.get("interval_seconds") not in (60, 300) or (end - start).total_seconds() != quote["interval_seconds"]:
+            return "완결 1~5분봉이 아닙니다"
+        if not quote.get("regular_session") or not opening <= start < end <= closing:
+            return "정규장 관측이 아닙니다"
+        if not opening <= now < closing:
+            return "현재 미국 정규장이 열려 있지 않습니다"
+        if start <= created:
+            return "주문 생성 뒤 시작된 새 관측이 아직 없습니다"
+        if end > now or fetched > now or fetched < end:
+            return "미래 시각 또는 아직 완결되지 않은 관측입니다"
+        if (now - end).total_seconds() > max_age or (now - fetched).total_seconds() > max_age:
+            return "무료 관측이 허용 지연 20분을 넘었습니다"
+    except (ValueError, TypeError, KeyError):
+        return "시세 시간대·정규장·가격 메타데이터가 불완전합니다"
+    return None

+def fill_orders(account, quotes, fx, current=None, max_age=1200):
+    migrate_account(account)
+    current = current or now_iso()
+    positions = {p["symbol"]: p for p in account["positions"] if p["quantity"] > 0}
+    completed = {trade["id"] for trade in account["trades"]}
+    for order in sorted(account["orders"], key=lambda row: row.get("side") != "매도"):
+        if order["status"] != "pending":
+            continue
+        if order["id"] in completed:
+            order["status"] = "filled"
+            continue
+        symbol = order["symbol"]
+        quote = quotes.get(symbol)
+        waiting = quote_waiting_reason(quote, order["created_at"], current, max_age)
+        if not fx or account.get("cash_usd") is None:
+            waiting = "실제 시장 환율·달러 현금 확보 전 체결 대기"
+        elif not math.isfinite(float(fx["rate"])) or fx["rate"] <= 0 or fx.get("as_of", "9999") > current[:10]:
+            waiting = "유효한 현재 또는 이전 관측 환율이 없습니다"
+        if waiting:
+            order["waiting_reason"] = waiting
+            continue
+        price, rate = float(quote["price"]), float(fx["rate"])
+        existing = positions.get(symbol, {}).get("quantity", 0)
+        side = "sell" if order["side"] == "매도" else "buy"
+        quantity = floor_quantity(min(existing, order["quantity"])) if side == "sell" else affordable_quantity(account["cash_usd"], price, order["quantity"])
+        if quantity <= 0:
+            order.update(status="cancelled", cancelled_at=current, cancel_reason="매도 가능 보유 또는 비용 포함 가용 달러가 부족합니다")
+            continue
+        amount = quantity * price
+        fees = trade_fees(amount, side)
+        fee = fees["total_usd"]
+        if side == "sell" and amount <= fee:
+            order["waiting_reason"] = "매도 대금이 공시 최소 비용보다 작아 체결을 대기합니다"
+            continue
+        position = positions.get(symbol, {"symbol": symbol, "name": SYMBOLS.get(symbol, symbol), "quantity": 0,
+                                           "cost_basis_usd": 0.0, "cost_basis_krw": 0.0})
+        old_cost, old_krw = position.get("cost_basis_usd"), position.get("cost_basis_krw")
+        realized = None
+        if side == "buy":
+            new_cost = old_cost + amount + fee if old_cost is not None else None
+            new_krw = old_krw + (amount + fee) * rate if old_krw is not None else None
+            new_quantity = existing + quantity
+        else:
+            fraction = quantity / existing
+            released = old_krw * fraction if old_krw is not None else None
+            realized = (amount - fee) * rate - released if released is not None else None
+            new_cost = old_cost * (1 - fraction) if old_cost is not None else None
+            new_krw = old_krw * (1 - fraction) if old_krw is not None else None
+            new_quantity = max(0, existing - quantity)
+        account["cash_usd"] += amount - fee if side == "sell" else -amount - fee
+        if account["cash_usd"] < -1e-8:
+            raise ArithmeticError("비용을 포함한 모의 주문이 가용 현금을 초과했습니다")
+        account["cash_usd"] = max(0.0, account["cash_usd"])
+        if new_quantity > 1e-9:
+            position.update(quantity=new_quantity, price_usd=price, cost_basis_usd=new_cost, cost_basis_krw=new_krw,
+                            average_cost_usd=new_cost / new_quantity if new_cost is not None else None)
+            positions[symbol] = position
+        else:
+            positions.pop(symbol, None)
+        trade = {"id": order["id"], "order_id": order["id"], "symbol": symbol, "name": SYMBOLS.get(symbol, symbol),
+                 "side": order["side"], "executed_at": quote["bar_end"], "recorded_at": current,
+                 "quantity": quantity, "price_usd": price, "amount_usd": amount, "amount_krw": amount * rate,
+                 "fee_usd": fee, "fee_krw": fee * rate, **fees, "fx_rate": rate, "fx_as_of": fx["as_of"],

+def parse_quote(symbol, chart, fetched_at, source_url):
+    meta = chart.get("meta", {})
+    if meta.get("symbol") != symbol or meta.get("currency") != "USD" or meta.get("instrumentType") != "ETF" or meta.get("dataGranularity") != "1m":
+        raise ValueError("요청 ETF·달러 통화·1분 간격 메타데이터가 일치하지 않습니다")
+    periods = meta.get("tradingPeriods", [])
+    if isinstance(periods, dict):
+        periods = periods.get("regular", [])
+    def flatten(value):

+        return [p for part in value for p in flatten(part)] if isinstance(value, list) else []

+        if session is None or end > fetched:

+            "session_close": datetime.fromtimestamp(session["end"], timezone.utc).isoformat(), "regular_session": True,

+            except Exception as error:

+                details[symbol] = traceback.format_exc()
+    return {"quotes": quotes, "errors": errors, "error_details": details, "fetched_at": fetched_at or now_iso(),
+            "status": "ready" if not errors else "partial" if quotes else "unavailable"}

+            delay = min(900, 60 * 2 ** min(errors, 4))

+        if finished.wait(delay):

## LEVEL 1 · 프로젝트 소개와 읽는 방법

10년 이상 장기 투자를 생각하며 시세를 배우고 가상 계좌로 운용 과정을 살펴보는 로컬 도구입니다.

**실제 돈을 투자하지 않습니다.** 예를 들어 화면의 “매수” 기록은 무료 시세와 비용 조건으로 계산한 모의체결이며 토스에 주문을 보냈다는 뜻이 아닙니다.

학습·운용이 현재 어느 단계인지, 무엇을 보유하는지를 함께 볼 수 있습니다.

## LEVEL 1 · 입력에서 처리와 출력까지

입력은 공개 시세입니다. 모델은 시세의 흐름을 배우고 후보 ETF를 고르며, 실제 거래 소 대신 가상 계좌에 대기·체결·환전을 기록합니다. 출력 화면은 그 기록과 학습 진행을 보여 줍니다.


## LEVEL 1 · 사용·실험 순서와 확인 방법

서버가 켜져 있으면 첫 화면의 대시보드 링크를 열고 꺼져 있으면 최종 폴더의 대시보드 실행.cmd를 사용합니다. 화면에서 현재 작업과 보유·거래를 읽습니다. 브라우저 창을 닫는 것과 운용 중지는 다르므로 학습을 멈추려면 “운용 중지”를 사용합니다.

## LEVEL 1 · 결과와 한계를 해석하는 기준

초기 시험의 예측 오차가 작아 보여도 돈을 더 벌었다는 뜻은 아닙니다. 초기 20 단계 시험 MAPE 원값은 추가 학습 약 0.7643%, 무변화 예측 약 0.7550%였으며 한 자리 요약은 둘 다 0.8%입니다. 같은 요약만 보고 모델이 더 좋다고 판단하지 않습니다.

## LEVEL 1 · 구현과 핵심 파일을 연결해 읽기

처음에는 실행 안내 → 보유·거래 화면 → 자료와 모의체결 범위 → 차수 설명 순서로 읽습니다. 서버는 화면을 제공하고 엔진은 학습·모의운용을 처리합니다. 학습한 가중치와 모의 원장은 공개 코드와 별도로 로컬에 보관됩니다.

## LEVEL 1 · 용어와 실수하기 쉬운 구분

ETF는 여러 자산에 묶어 투자할 수 있도록 거래소에 상장한 상품입니다.

이 프로젝트의 모의 계좌는 실제 돈을 보내지 않고 계산으로만 보유·체결을 기록합니다.

일봉·분봉은 각각 하루·분 단위로 묶은 시세이며 완결 봉은 해당 시간이 끝난 관측입니다.

가중치는 학습한 모델에 저장된 값이고 추가 학습은 그 값을 이어 갱신하는 일입니다.

MAPE는 예측과 실제 값의 상대 오차를 평균한 지표로 투자 수익률과 다릅니다.

**실제 토스 계좌·주문과 연결하지 않는 모의운용입니다.** 무료 자료가 없거나 오래되면 대기하며 소급 체결을 만들지 않습니다. 같은 표본 반복·추가 학습·독립 시험을 구분하고 수익·원금 보존·실거래 성능을 보장하지 않습니다.

## LEVEL 1·4차 학습 자료와 평가 경계

ETF는 여러 자산을 묶어 거래하는 상품이고 일봉은 하루 가격 기록입니다. 과거 자료와 시험 이후 새 자료는 따로 나누어 학습합니다.

| 구간 | 날짜 | 역할 |
| --- | --- | --- |
| 과거 학습 | 2024-06-03 이하 | 자산별 학습 |
| 검증 | 2024-06-04~2025-08-21 | 모든 자산 학습에서 제외 |
| 시험 | 2025-08-22~2026-11-06 | 모든 자산 학습에서 제외 |
| 이후 학습 | 2026-11-06 초과 | 과거 구간과 분리 |

15개 ETF와 KRW =X의 수집 가능한 전체 일봉을 요청합니다. 2020년 이전 누락 이력과 제공되는 2000년 이전 이력도 대상입니다.

환율은 **독립 단변량**이며 ETF 공 변 량이나 인과 학습이 아닙니다.

같은 Chronos-2 마지막 가중치를 이어 쓰며 4차 성과는 아직 측정되지 않았습니다. [4차 사용 안내](../../4차/사용%20안내.md)

## LEVEL 1·5차 과적합 위험 방어

ETF 가격은 날마다 쌓이는 기록이고 모델 가중치는 그 기록을 배운 결과를 저장한 값입니다. 같은 기록을 쉬지 않고 되풀이해 외우면 새로운 상황에 약해질 수 있습니다. 5차는 새로 배울 날짜가 없으면 학습을 기다리고 자료 수집과 가상 운용은 계속합니다.

예를 들어 새 날짜가 생기면 과거 자료도 다시 볼 수 있지만 같은 자료뿐인 데 회 차를 계속 시작하지 않도록 예약을 기록합니다. 새로 배운 뒤 기존 세 ETF의 정해진 확인 자료에서 오차가 나빠지면 운영 중인 저장 값을 바꾸지 않습니다. 사용 전 실행 상태와 오류를 확인해야하며 실제 돈으로 주문하지 않습니다.

5차 학습 반복은 고정 시험 구간을 호출하지 않습니다. 기존 `기준모델평가.json`·`최초시험평가.json`은 읽어서 보존하며 파일이 없으면 학습 중 새 시험 평가를 계산하거나 생성하지 않고 미측정으로 둡니다. 독립 시험은 학습 반복과 분리해야 하며 별도 시험 실행 도구는 현재 제공하지 않습니다.

| 조건 | 5차 방어 설계 |
| --- | --- |
| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
| 학습 설정 | 최대 25 단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한 값·표본 수 확인 |
| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |

새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다.

고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다.

세 ETF 기준은 전체 15 종과 환율에 대한 독립 성과를 입증하지 않습니다.

미래 전진 평가는 별도로 유지합니다.

과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

## LEVEL 1 · 항목별 자세한 풀이와 확인 지점

### LEVEL 1 · 실행

이 항목은 다음 실제 조건으로 동작합니다. 용어는 앞선 설명과 연결하고 값·입력·출력이 무엇을 가리키는지 함께 읽습니다.

3차 당시에는 3차 서버·엔진과 1차 전용 환경·비공개 저장소를 함께 사용했습니다. 5차 실행 전환은 완료되지 않았습니다. 공개 코드에는 가중치와 실행 환경을 포함하지 않습니다.

서버가 켜져 있으면 [대시보드](http://127.0.0.1:8879/)를 엽니다.

서버가 꺼져 있으면 프로젝트 최종 폴더의 `대시보드 실행.cmd`를 실행합니다.

중지·재개와 비용 재현 범위는 [사용 안내](../../3%EC%B0%A8/%EC%82%AC%EC%9A%A9%20%EC%95%88%EB%82%B4.md)에서 확인합니다.

## 비용과 공개 범위

토스 기본 매매 수수료 0.1%와 공개 기본 환전·SEC 비용 가정을 반영합니다. 실제 거래 가능 종목·호가·결제·배당 지급일·환율·세금 전체와 같지는 않습니다. 실제 토스 주문을 전송하지 않습니다. 시세 원본·가중치·모의 원장·인증정보·개인 지침·운영 기록은 공개에서 제외합니다.

논문·원고가 없는 소프트웨어 프로젝트입니다. 단위·표시·API 경계 검사와 별도 검토를 수행하며, 공개 반영은 현재 원격 커밋·전체 tree·주요 HTTP 원문과 차수 링크로 확인합니다. 과거 실패와 미검증 UI 범위는 별도 로컬 기록에 남깁니다.

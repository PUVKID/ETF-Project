## 프로젝트 소개와 읽는 방법

이 프로젝트를 학습 자료 → 같은 모델의 이어 학습 → ETF 선택 → 주문 대기·체결 → 보유·손익 화면의 연결로 읽습니다. 장기 계획, 학습 오차, 과거 비교, 운용 뒤 쌓인 모의거래는 서로 다른 종류의 정보입니다. **차수 번호는 프로그램 변경 묶음**이며 독립 투자 시험 횟수가 아닙니다.

<a id="level-2--실제-기능과-동작-범위"></a>

## 실제 기능과 동작 범위

학습은 완결 일봉을 읽고 모의 체결은 정규 장 완결 1분봉 관측을 사용합니다.

자동 선택은 예측만이 아니라 비용·현금 제약과 함께 작동하며 대기·취소·체결 이유를 구분합니다.

토스 지원 전 종목을 검증한 도구로 확대해서 해석하지 않습니다.

## 용어와 실수하기 쉬운 구분

ETF는 여러 자산에 묶어 투자할 수 있도록 거래소에 상장한 상품입니다.

| 역할·조건 | 동작과 확인할 내용 |
| --- | --- |
| **가상 보유·체결 기록** | 이 프로젝트의 모의 계좌는 실제 돈을 보내지 않고 계산으로만 보유·체결을 기록합니다. |
| **일봉·분봉·완결 봉** | 일봉·분봉은 각각 하루·분 단위로 묶은 시세이며 완결 봉은 해당 시간이 끝난 관측입니다. |
| **가중치와 추가 학습** | 가중치는 학습한 모델에 저장된 값이고 추가 학습은 그 값을 이어 갱신하는 일입니다. |
| **MAPE와 투자 수익률** | MAPE는 예측과 실제 값의 상대 오차를 평균한 지표로 투자 수익률과 다릅니다. |
| **체결 확인** | **실제 토스 계좌·주문과 연결하지 않는 모의운용입니다.** 무료 자료가 없거나 오래되면 대기하며 소급 체결을 만들지 않습니다. |

같은 표본 반복·추가 학습·독립 시험을 구분하고 수익·원금 보존·실거래 성능을 보장하지 않습니다.

<a id="level-24차-학습-자료와-평가-경계"></a>

## 4차 학습 자료와 평가 경계

자료 제공 기간은 자산마다 다릅니다.

오래된 이력도 수집 가능한 만큼 요청하며 환율은 ETF와 별개 시계열로 배웁니다.

| 구간 | 날짜 | 역할 |
| --- | --- | --- |
| 과거 학습 | 2024-06-03 이하 | 자산별 학습 |
| 검증 | 2024-06-04~2025-08-21 | 모든 자산 학습에서 제외 |
| 시험 | 2025-08-22~2026-11-06 | 모든 자산 학습에서 제외 |
| 이후 학습 | 2026-11-06 초과 | 과거 구간과 분리 |

15개 ETF와 KRW=X의 수집 가능한 전체 일봉을 요청합니다.

2020년 이전 누락 이력과 제공되는 2000년 이전 이력도 대상입니다.

환율은 **독립 단변량**이며 ETF 공변량이나 인과 학습이 아닙니다.

같은 Chronos-2 마지막 가중치를 이어 쓰며 4차 성과는 아직 측정되지 않았습니다.

<a id="level-25차-과적합-위험-방어"></a>

## 5차 과적합 위험 방어

| 역할·조건 | 동작과 확인할 내용 |
| --- | --- |
| **가중치 확인** | 수집 → 새 날짜 확인 → 영속 예약 → 제한 학습 → 기존 가중치와 학습 후 가중치의 같은 검증 자료 검사 → 운영 반영의 순서입니다. |
| **날짜 조건** | 예약이 없거나 새 날짜가 없으면 학습하지 않고 수집과 모의운용을 지속합니다. |

학습 전 예약은 중간 실패 뒤 같은 관측 집합만으로 새 회차를 반복 예약·재시작하지 않도록 합니다.

MAE와 MAPE는 예측 오차 지표이며 두 값 중 하나라도 악화되거나 숫자가 유한하지 않거나 표본이 없으면 반영하지 않습니다.

이 검사는 기존 세 종목의 고정 자료에 한정됩니다.

5차 학습 반복은 고정 시험 구간을 호출하지 않습니다.

기존 `기준모델평가.json`·`최초시험평가.json`은 읽어서 보존하며 파일이 없으면 학습 중 새 시험 평가를 계산하거나 생성하지 않고 미측정으로 둡니다.

독립 시험은 학습 반복과 분리해야 하며 별도 시험 실행 도구는 현재 제공하지 않습니다.

| 조건 | 5차 방어 설계 |
| --- | --- |
| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
| 학습 설정 | 최대 25 단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한 값·표본 수 확인 |
| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |

| 역할·조건 | 동작과 확인할 내용 |
| --- | --- |
| **학습 허용과 예약** | 새 날짜는 새 회차를 허용하는 조건입니다. |
| **허용 자료의 재표본 추출** | 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. |
| **신규 행 학습의 한계** | 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다. |

발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다.

검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다.

예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다.

고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다.

세 ETF 기준은 전체 15 종과 환율에 대한 독립 성과를 입증하지 않습니다.

미래 전진 평가는 별도로 유지합니다.

과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

## 논문·원고와 원본 자료의 범위

첫 화면에서 논문·원고가 없는 소프트웨어 프로젝트임을 밝힙니다. 코드·사용 안내·자료 범위·검증 및 차수 비교를 연결하며 투자 성과를 논문 결과로 만들지 않습니다. 시세 원본·가중치·모의 원장은 공개하지 않습니다.

회차마다 모델을 경쟁시키거나 채택하지 않습니다. 3차에서는 최초 세 ETF의 고정 학습·검증·시험 구간과 기준 평가를 보존하고 신규 ETF의 과거 학습을 원래 학습 종료 일 이하로 제한했습니다. 4차의 학습 범위는 위 표를 따릅니다.

최초 시험 종료 뒤 새 자료는 추가 학습이며 독립 시험 성과가 아닙니다.

약 두 달 학습은 운용 계획입니다. PC와 로컬 프로세스 실행 중 반복하며 전원·절전·인터넷·프로세스 중단의 영향을 받습니다. 같은 표본의 반복 횟수와 독립 원본 수를 구분합니다.

초기 20 단계 시험 MAPE 원값은 추가 학습 약 0.7643%, 무변화 예측 약 0.7550%였으며 요약은 각각 0.8%, 0.8%입니다. 투자 수익 우위가 입증된 결과는 아닙니다.

과거 모의 비교, 운용 후 쌓이는 전진 기록, 가정 수익률 시나리오는 다릅니다. 사전 학습 데이터의 개별 자산·시점 경계는 확인되지 않았습니다. 10년은 계획 기간이며 짧은 ETF 이력을 10년 실측 성과로 만들지 않습니다. 수익·원금 보존·실거래 성능을 보장하지 않습니다.

## 수치와 원값

백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율·전체 정밀도를 펼쳐 확인합니다. 반올림된 100.0%와 실제 모든 정답을 구분합니다. 원값 스냅샷은 직접 갱신하고 원본 결과를 표시 목적으로 바꾸지 않습니다. 1·2차의 이전 표시 방식은 역사적 문서에 보존합니다.

## 비용과 공개 범위

토스 기본 매매 수수료 0.1%와 공개 기본 환전·SEC 비용 가정을 반영합니다. 실제 거래 가능 종목·호가·결제·배당 지급일·환율·세금 전체와 같지는 않습니다. 실제 토스 주문을 전송하지 않습니다. 시세 원본·가중치·모의 원장·인증정보·개인 지침·운영 기록은 공개에서 제외합니다.

논문·원고가 없는 소프트웨어 프로젝트입니다. 단위·표시·API 경계 검사와 별도 검토를 수행하며, 공개 반영은 현재 원격 커밋·전체 tree·주요 HTTP 원문과 차수 링크로 확인합니다. 과거 실패와 미검증 UI 범위는 별도 로컬 기록에 남깁니다.

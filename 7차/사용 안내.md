현재 상태: 7차 화면은 8880에서 제공하며 기존 6차 데이터 서버 8879를 중계합니다. 2026-11-26 인계 확인에서는 8879가 꺼져 API 503을 표시했습니다. 화면 서버 실행과 데이터 운용 재개는 별개이며 이번 변경으로 학습·수집·모의운용을 새로 시작하지 않았습니다.

| 목적 | 명령과 조건 |
| --- | --- |
| 화면 서버 | Python 표준 라이브러리로 7차에서 `python -B -X utf8 server.py --port 8880` 실행 |
| 화면 열기 | `http://127.0.0.1:8880/` |
| 데이터 연결 | 기존 6차 서버가 127.0.0.1:8879에서 응답해야 함. 이 화면 서버는 기존 엔진을 자동 시작하지 않음 |
| 작업 버튼 | 기존 `/api/jobs`의 start·stop·refresh·train을 검증 후 한 번 중계. 데이터 서버가 꺼졌으면 503 반환 |
| 현재 UI | 배포된 생성 CSS를 그대로 읽으며 Rust·npm 빌드 없이 화면 서버 실행 가능 |
| 테마 재생성 | `테마생성.py`가 `E:/2026/Astryx 공통 디자인/1차/target/release/astryx-theme.exe`를 두 번 호출 |

## Rust 빌드 의존성과 재현

[자체 Rust 원문](의존성/Rust%20테마%20엔진/)은 당시 사용한 Cargo.toml·Cargo.lock·src/main.rs의 바이트를 보존했습니다. Rust 2024 edition과 Windows용 Rust/MSVC 도구가 필요하며 `cargo build --release --manifest-path "의존성/Rust 테마 엔진/Cargo.toml"`로 빌드합니다. 이 명령은 원문에서 실행 파일을 만드는 방법이며 이번 공개 과정에서 재빌드하지 않았습니다.

현재 테마 생성 스크립트는 원래 공통 엔진의 위 E 경로와 `node_modules/@astryxdesign/theme-neutral/dist/theme.css`를 참조합니다. 다른 컴퓨터에서 CSS를 재생성하려면 해당 공통 경로에 빌드 결과와 공식 `@astryxdesign/theme-neutral` 0.7.17을 준비해야 합니다. 이미 포함된 CSS의 화면 실행과 CSS 재생성 환경을 구분합니다. 공식 테마는 MIT 원문을 보존하며 자체 코드에 새 라이선스를 임의 부여하지 않습니다.

## 검사와 제한

`검사.py`에는 격리 HTTP 서버로 원본 서버를 시작하지 않는 요청 경계 검사가 있습니다. 보존 대조 항목은 비공개 `work/화면원본_고정목록_비공개.json`과 기존 6차 경로를 필요로 하므로 공개 파일만 내려받은 환경에서 전체 검사 완료를 보장하지 않습니다. 해당 비공개 목록·운영 로그·검토문·모델·계좌는 게시하지 않습니다. 기존 최종 소스에 대한 독립 검사 근거를 재사용했으며 이 문서 연결 때문에 학습이나 전체 UI 검사를 반복하지 않았습니다.

화면 변경은 예측 성과·수익·실제 주문 기능 추가를 뜻하지 않습니다. 라이트/다크·필터·원값 확인·기존 연구 한계는 유지합니다.

> 디자인 이력 안내: 최신 화면은 현재 운용 6차에 통합되었습니다. 아래 8880·프록시 설명은 당시 이력이며 현재 기본 실행은 [6차 안내](../../6차/사용%20안내.md)의 8879입니다.

# 7차 · Astryx 화면 적용

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

기존 연구와 앱의 숫자를 보여주는 화면을 새 차수에 옮겼습니다. 라이트는 밝은 화면, 다크는 어두운 화면이며 선택한 모드를 다시 열 때 기억합니다. 숫자와 원본 사진·모델은 화면 디자인 때문에 새로 만들지 않습니다.

| 사용자가 확인할 부분 | 동작 | 주의 |
|---|---|---|
| 왼쪽 탐색 | 원래 기능 화면이나 내용으로 이동 | 탐색만으로 실험을 실행하지 않음 |
| 버튼·표·입력 | 같은 간격과 포커스·선택·비활성 표시 | 실제 값이 없으면 미기록/미측정 |
| 연결 실패 | 원래 상태를 읽지 못한 사실을 표시 | 실패를 정상 결과로 바꾸지 않음 |

기존 6차의 청회색 팔레트와 나눔고딕700을 유지하고 탐색·카드·체결 표·입력·버튼의 크기와 상태를 Astryx 토큰에 연결했습니다.

실제 API200·DOM 표시 대기 뒤 브라우저10항목을 통과했습니다. 실제 주문·학습·중지 버튼은 누르지 않았고 그 요청 중계는 격리 서버에서 검사했습니다.

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer

화면 요소의 배경·선·글자·간격을 공통 토큰으로 연결합니다. 토큰은 같은 역할을 여러 화면에서 일관되게 표현하는 이름입니다. 프로젝트의 지정 팔레트는 유지하며 다른 프로젝트의 색을 복사하지 않습니다.

| 단계 | 입력 | 출력 |
|---|---|---|
| Rust 테마 생성 | 기존 팔레트와 light/dark | Astryx CSS 토큰 |
| 기존 DOM 연결 | 공식 중립 테마·생성 토큰·화면 어댑터 | 실제 버튼·카드·표·입력 상태 |
| 기존 데이터 조회 | 원래 허용 API/상태 | 화면의 수치·시각·오류 |

기존 8879 서버의 /api/state·/api/trades를 중계합니다. /api/jobs는 로컬 Host·출처·JSON·기존 action 검증 뒤 같은 원래 서버로 한 번만 전달합니다. 새 JobManager·학습·계좌를 만들지 않습니다.

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner

기존 실행 환경을 보존한 상태에서 새 차수의 `server.py --port 8880`를 별도로 실행합니다. 화면 주소는 `http://127.0.0.1:8880/`입니다. 정지·학습·주문을 위한 새로운 실행 경로를 만드는 절차가 아닙니다.

| 순서 | 확인 | 결과를 읽는 법 |
|---|---|---|
| 1 | 실제 관측 시각과 연결 문구 | 오래된 관측은 현재 실행으로 단정하지 않음 |
| 2 | 라이트/다크 전환 후 새로고침 | 같은 선택이 복원됨 |
| 3 | 탐색·필터·상세 펼침 | 원래 정보와 기능을 확인 |
| 4 | 390px와 데스크톱 | 표는 내부 스크롤, 문서는 가로로 잘리지 않아야 함 |

실제 API200·DOM 표시 대기 뒤 브라우저10항목을 통과했습니다. 실제 주문·학습·중지 버튼은 누르지 않았고 그 요청 중계는 격리 서버에서 검사했습니다.

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced

원래 소스·데이터·환경을 수정하지 않고 필요한 화면 코드와 자산만 새 차수로 복사했습니다. JSON·모델·의료 원본·DB·가상환경은 화면 배포물에 복제하지 않습니다. 원본 화면 파일은 크기·SHA-256을 고정한 비공개 목록으로 대조합니다.

| 경계 | 구현 | 검증 |
|---|---|---|
| 정적 파일 | 새 화면 root 안의 파일, 경로 이탈·숨김·연결 경로 거부 | 격리 loopback HTTP |
| API | 기존 8879 서버의 상태·체결 조회와 검증된 기존 작업 요청을 한 번 중계 | Host·출처·형식·없는 경로·연결 실패 |
| 화면 | 원래 기능 DOM·데이터 처리 유지 | 실제 브라우저 조작·폰트·테마·폭 |
| Rust | `테마생성.py`의 실제 subprocess 호출 | argv·종료0·stdout해시와 CSS 연결 |

ETF는 기존 vanilla DOM을 공식 토큰·중립 CSS와 연결한 구현이며 React 컴포넌트를 직접 사용하지 않습니다.

<a id="reading-level-5"></a>
## LEVEL 5 - Expert

공식 패키지는 `@astryxdesign/core`·`@astryxdesign/theme-neutral` 0.7.17입니다. MIT 원문을 `Astryx-MIT-LICENSE.txt`에 보존합니다. 생성 CSS는 `--color-primary`, 배경·본문·보조·테두리·간격·반경·44px 컨트롤·2px 포커스 토큰을 기존 선택자에 연결합니다. 빌드 시 Rust 호출이며 런타임 Rust 렌더러나 GPU 가속이라고 표현하지 않습니다.

| 증거 | 범위 | 대신하지 않는 것 |
|---|---|---|
| `검사.py` | 8개 메서드 중 프로젝트별 미적용 분기를 제외한 보존·문법·CSS 연결·HTTP 경계 | 실제 연구 성능·실주문 |
| 브라우저 기록 | 1440×1000·390×844, 양테마·저장·탐색·오류 | 모든 환경의 절대 무결함 |
| 로컬 코드 그래프 | code-only AST와 질의, EXTRACTED/INFERRED 구분 | 인증·완료 영수증 |
| 독립 검증 | 부모가 별도 담당자에게 배정 | 구현자의 자기 승인 |

ETF 6차의 모델·예측·비용·원장·일봉/1분봉 신선도와 금융 연구 한계는 그대로입니다. UI 변경으로 예측 성능이나 수익 개선을 주장하지 않습니다.

같은 소스·입력·환경의 기존 유효 검사 결과는 재사용하고 변경된 UI와 연결 경계만 보완합니다. 실패·수리·입력 보정과 과거 차수는 보존합니다. 공개용 파일·원격 링크·독립 검토가 끝나기 전 전체 공개 완료로 보고하지 않습니다.

## 인계 이후 공개 안내

현재 상태: 7차 화면은 8880에서 제공하며 기존 6차 데이터 서버 8879를 중계합니다. 2026-11-26 인계 확인에서는 8879가 꺼져 API 503을 표시했습니다. 화면 서버 실행과 데이터 운용 재개는 별개이며 이번 변경으로 학습·수집·모의운용을 새로 시작하지 않았습니다.

| 항목 | 6차 | 7차 |
| --- | --- | --- |
| 화면 주소 | 8879의 운영 화면 | 8880의 별도 화면 |
| 데이터 처리 | 기존 모델·수집·모의계좌 | 기존 8879 API 중계, 새 계좌·작업자 생성 없음 |
| 화면 토큰 | 기존 CSS | 공식 Astryx 중립 CSS·Rust 생성 테마·선택자 어댑터 |
| 조작 상태 | 기존 기능 유지 | 44px·hover·Tab 포커스·양테마·390/1440px 확인 |
| 연결 실패 | 기존 서버 경계 | 503 경고 표시, 정상 데이터로 가장하지 않음 |

독립 검토는 UI 최종 원문·실제 Rust 두 모드 생성 결과·로컬 code-only 그래프를 대조한 기존 근거입니다. 현재 503을 연결 성공으로 확대하지 않습니다. Graphify 추출 84노드·153관계는 직접 추출 147개와 추론 6개를 구분하며 실제 make_server·reader·do_GET·do_POST 소스와 대조했습니다. 그래프는 성능이나 완전 무결함 증거가 아닙니다.

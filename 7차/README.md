# ETF 장기투자 모의운용 · 7차

기존 실행을 보존하면서 새 차수에 Astryx 화면을 연결했습니다. **화면 변경과 연구·운영 결과는 별개**입니다.

| 구분 | 실제 적용 | 확인과 제한 |
|---|---|---|
| 화면 | 기존 6차의 청회색 팔레트와 나눔고딕700을 유지하고 탐색·카드·체결 표·입력·버튼의 크기와 상태를 Astryx 토큰에 연결했습니다. | 기존 기능·원본 보존 |
| 데이터 | 기존 8879 서버의 /api/state·/api/trades를 중계합니다. /api/jobs는 로컬 Host·출처·JSON·기존 action 검증 뒤 같은 원래 서버로 한 번만 전달합니다. 새 JobManager·학습·계좌를 만들지 않습니다. | 원래 데이터·상태를 읽음 |
| Rust | 공통 astryx-theme.exe를 빌드 시 두 번 실제 호출해 라이트·다크 CSS 생성 | 생성 CSS를 실제 HTML에 로드 |
| 확인 | 실제 API200·DOM 표시 대기 뒤 브라우저10항목을 통과했습니다. 실제 주문·학습·중지 버튼은 누르지 않았고 그 요청 중계는 격리 서버에서 검사했습니다. | 구현자 확인이며 독립 검증 전 |
| 한계 | ETF 6차의 모델·예측·비용·원장·일봉/1분봉 신선도와 금융 연구 한계는 그대로입니다. UI 변경으로 예측 성능이나 수익 개선을 주장하지 않습니다. | 성능 전후 실측 없음 |

실행 진입점은 `server.py --port 8880`, 화면 주소는 `http://127.0.0.1:8880/`입니다. 원래 서버를 종료하거나 포트를 바꾸지 않습니다. 실제 확인한 Python 실행 파일과 cwd는 로컬 비공개 인계에 기록합니다.

테마는 `테마생성.py`가 공통 Rust 실행 파일을 호출해 생성합니다. 기존 JavaScript와 HTML이 공식 중립 CSS·생성 토큰·화면 어댑터를 직접 로드하므로 Vite 빌드는 필요하지 않습니다. 환경·데이터·모델 복제나 새 연결 폴더는 만들지 않습니다.

## 2026-11-26 조작 상태 보완

기존 선택자보다 Astryx 어댑터의 최소 44px 규칙이 우선하도록 연결했습니다. 1440px·390px, 라이트·다크에서 크기·넘침·마우스 오버와 실제 Tab 키 포커스를 확인한 17개 항목을 통과했습니다. 이 결과는 구현 측 확인이며 독립 검토 완료와 구분합니다.

재개 시 화면 서버만 기동했습니다. 기존 데이터 백엔드가 연결되지 않은 상태를 화면에 표시하며, 과거 API 정상 기록을 현재 연결 성공으로 확대하지 않습니다. 학습·수집·거래 엔진을 시작하거나 기존 정지 설정을 변경하지 않았습니다.

## 공개 인계와 현재 연결 상태

현재 상태: 7차 화면은 8880에서 제공하며 기존 6차 데이터 서버 8879를 중계합니다. 2026-11-26 인계 확인에서는 8879가 꺼져 API 503을 표시했습니다. 화면 서버 실행과 데이터 운용 재개는 별개이며 이번 변경으로 학습·수집·모의운용을 새로 시작하지 않았습니다.

| 항목 | 6차 | 7차 |
| --- | --- | --- |
| 화면 주소 | 8879의 운영 화면 | 8880의 별도 화면 |
| 데이터 처리 | 기존 모델·수집·모의계좌 | 기존 8879 API 중계, 새 계좌·작업자 생성 없음 |
| 화면 토큰 | 기존 CSS | 공식 Astryx 중립 CSS·Rust 생성 테마·선택자 어댑터 |
| 조작 상태 | 기존 기능 유지 | 44px·hover·Tab 포커스·양테마·390/1440px 확인 |
| 연결 실패 | 기존 서버 경계 | 503 경고 표시, 정상 데이터로 가장하지 않음 |

독립 UI·Rust·HTTP 경계 검토는 인계된 최종 소스의 기존 근거를 재사용합니다. 44px·양테마·반응형·hover·실제 Tab 포커스 17항목과 별도 검토가 통과했습니다. 위 API 200 기록은 11월 25일 당시 확인이며 현재 연결 성공을 뜻하지 않습니다.

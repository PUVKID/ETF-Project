# 7차 변경 기록

| 구분 | 파일 | 이유 |
|---|---|---|
| 추가 | server.py | 기존 실행과 새 화면 분리 |
| 추가 | 테마생성.py·테마설정.json | Rust 두 모드 생성과 프로젝트 팔레트 유지 |
| 추가 | astryx-official.css·astryx-theme.css·astryx-adapter.css | 공식 CSS·실제 생성 토큰·기존 화면 연결 |
| 추가 | 검사.py·README.md·docs/차수설명.md | 화면 계약·요청 경계·사용 안내 |
| 보존 복사 | 기존 화면 코드·폰트·OFL·자산 | 필요한 화면 소스만 보존 |
| 수정 | HTML의 공식 중립 CSS·생성 토큰·화면 어댑터 연결 | 기존 JavaScript·기능을 유지한 실제 로딩·두 테마 적용 |

기존 6차의 청회색 팔레트와 나눔고딕700을 유지하고 탐색·카드·체결 표·입력·버튼의 크기와 상태를 Astryx 토큰에 연결했습니다.

실제 API200·DOM 표시 대기 뒤 브라우저10항목을 통과했습니다. 실제 주문·학습·중지 버튼은 누르지 않았고 그 요청 중계는 격리 서버에서 검사했습니다.

ETF 6차의 모델·예측·비용·원장·일봉/1분봉 신선도와 금융 연구 한계는 그대로입니다. UI 변경으로 예측 성능이나 수익 개선을 주장하지 않습니다.

데이터·환경·모델·운영 로그·개인 지침은 공개용 묶음에 넣지 않습니다. [전체 차이](전체비교.diff)에는 화면과 신규 구현의 공백·주석 차이를 포함하고 비공개 원장은 제외합니다.


## 2026-11-26 조작 상태 보완

기존 선택자보다 Astryx 어댑터의 최소 44px 규칙이 우선하도록 연결했습니다. 1440px·390px, 라이트·다크에서 크기·넘침·마우스 오버와 실제 Tab 키 포커스를 확인한 17개 항목을 통과했습니다. 이 결과는 구현 측 확인이며 독립 검토 완료와 구분합니다.

재개 시 화면 서버만 기동했습니다. 기존 데이터 백엔드가 연결되지 않은 상태를 화면에 표시하며, 과거 API 정상 기록을 현재 연결 성공으로 확대하지 않습니다. 학습·수집·거래 엔진을 시작하거나 기존 정지 설정을 변경하지 않았습니다.

## 공개 연결 보완

전체 차수 표·다섯 읽기 수준·사용 안내·Rust 원문과 재생성 조건·전체 공개 비교를 연결했습니다. 원래 화면·서버·생성 스크립트는 변경하지 않았습니다. 기존 6차와 과거 원문·비교는 보존하며 비공개 증거는 공개하지 않습니다.

현재 상태: 7차 화면은 8880에서 제공하며 기존 6차 데이터 서버 8879를 중계합니다. 2026-11-26 인계 확인에서는 8879가 꺼져 API 503을 표시했습니다. 화면 서버 실행과 데이터 운용 재개는 별개이며 이번 변경으로 학습·수집·모의운용을 새로 시작하지 않았습니다.

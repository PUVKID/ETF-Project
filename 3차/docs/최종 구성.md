# 최종 구성

최종 폴더는 3차 납품 원본에서 준비한 `대시보드 실행.cmd`와 `사용 안내.md` 두 파일로 구성합니다. 실행 파일은 같은 프로젝트 3차 서버와 1차 전용 실행 환경을 참조합니다.

기존 최종 2차 파일은 2차 납품 자료의 크기·해시와 일치하는지 확인한 뒤 새 검증 파일로 교체합니다. 코드·모델·원장·검증 기록은 최종 폴더로 복사하지 않습니다. 새 최종 파일의 목록·크기·SHA-256과 교체 경계 확인은 비공개 운영 기록으로 보존합니다.

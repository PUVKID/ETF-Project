# 3차 상세

2차에서 원값 확인과 화면 조작을 보완한 뒤, 이번 차수에서는 현재 모의계좌의 보유와 거래를 직접 확인하고 모델이 ETF를 자동 선택하도록 운용 범위를 넓혔습니다. 코드·문서 차수이며 3차 학습 모델을 별도로 경쟁 채택하는 의미는 아닙니다.

## 보유와 거래

보유 표에는 종목·수량·평균 매입가·원화 원가·평가·미실현손익을 표시합니다. 대기·체결·취소 주문은 상태와 이유를 남기고 ETF 매수·매도 체결은 전체 기록의 페이지와 필터로 확인합니다. 환전 내역은 ETF 체결과 분리합니다. 과거 원가가 확인되지 않으면 임의의 평단을 만들지 않습니다.

후보 15개는 주식·해외주식·채권·금·업종으로 구성합니다. 모델 신호와 거래비용·현금 제약으로 자동 선택하며 모든 ETF를 다 거래해야 한다는 규칙은 없습니다. 기존 기본 수수료·환전·SEC 가정을 유지합니다. [후보와 출처·체결 범위](자료와%20모의체결%20범위.md)에 한계를 설명했습니다.

## 모의체결과 학습 자료

기존 일봉 방식에서 다음 완결 거래일까지 기다리던 전진 계좌 체결을 주문 후 정규장 완결 1분봉 관측으로 바꿉니다. 현재 정규장·최대 20분 지연·주문 이후 관측 조건을 충족해야 체결합니다. 신호는 정책 버전과 후보 목록으로 구분해 보존하고 이전 주문의 변경 이유도 남깁니다. 오래된·미래·장외 관측으로 소급 거래를 만들지 않습니다.

기존 최초 세 ETF의 고정 학습·검증·시험 자료와 평가 기준은 보존합니다. 새 ETF의 과거 학습은 원래 학습 종료일 이하만 별도 동결하며 시험 종료 이후 새 자료는 추가 학습으로 구분합니다. 같은 Chronos-2 마지막 가중치를 이어 학습합니다. 새 자료와 같은 자료 반복 학습은 다릅니다.

## 수치 표시

백분율은 소수 첫째 자리 반올림으로 바꾸고 원비율·전체 정밀도를 보존합니다. 100.0%로 반올림된 값과 실제 모든 정답을 구분합니다. 2차의 버림 규칙은 이전 문서에 역사적으로 남깁니다.

## 검사와 확인 범위

검사는 미래·오래된 가격·시장 시간·현금·중복 체결·원가와 손익·수수료·마이그레이션·페이지 API 경계와 숫자 반올림을 다룹니다. 독립 검토 기록과 원격 전체 tree·원문 대조는 공개 소스 밖에 보관합니다. 화면에서 확인하지 않은 전체 hover·확대·운영체제 모션·터치 조합을 정상으로 단정하지 않습니다.

## 학습 감시와 복구

후속 운영 점검에서 치명 CUDA 오류를 같은 프로세스에서 재시도하는 한계를 확인해 별도 감시 프로세스를 추가했습니다. 확인된 치명 오류만 복구 종료 코드로 반환하고 감시자가 제한된 간격으로 새 프로세스를 실행합니다. 일반 오류의 기존 대기 복구와 사용자 중지 경계를 유지합니다. 현재 미저장 단계를 정상 저장으로 꾸미지 않고 마지막 검증된 체크포인트에서 이어갑니다. [NVIDIA 런타임 오류 계약](https://docs.nvidia.com/cuda/archive/12.4.1/pdf/CUDA_Runtime_API.pdf)을 근거로 프로세스 수명을 분리했으며 모든 장치 장애의 자동 복구를 보장하지 않습니다.

## 확인 결과

구현 검사 54개와 화면 표시 검사 85개가 통과했습니다. 독립 검토 중 발견한 예측 계산 뒤 중지 재확인 누락과 감시자 기동 시 조회 잠금 충돌은 별도 회귀와 함께 수정했습니다. 320·390·760px 실제 화면의 보유·체결 메뉴 앵커와 표 키보드 이동, 비어 있지 않은 격리 60건의 페이지·필터를 확인했습니다. 시험 자료를 운영 계좌에 넣지 않았습니다.

[공백·주석·바이너리를 포함한 실제 전체 비교](3차%20전체%20비교.md)를 연결합니다. 시세·가중치·원장·개인설정·인증정보는 공개 대상이 아니며 논문 원고는 없는 소프트웨어 차수입니다.

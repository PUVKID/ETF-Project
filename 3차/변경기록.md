# 변경 기록

## 3차 · 2026-11-10

현재 보유, 주문 상태, 전체 ETF 체결 내역, 환전을 구분해 표시하고 체결 내역 페이지·방향 필터를 추가했습니다. 자동 후보는 기존 세 종목에서 주식·채권·금·업종을 포함한 15개로 넓혔습니다. 전진 체결에는 주문 뒤 정규장 완결 1분봉의 시간·지연·현금 제약을 적용합니다.

기존 모의 원금과 원장·가중치·고정 시험 자료를 보존하고 신규 후보 학습 자료와 정책 버전을 분리합니다. 백분율 요약은 최신 표시 기준에 따라 소수 첫째 자리 반올림으로 바꾸며 전체 원값은 유지합니다.

치명적인 CUDA 실행 실패는 손상된 문맥 안에서 계속 재시도하지 않고, 감시 프로세스가 마지막 저장 가중치로 새 학습 프로세스를 실행하도록 보완했습니다. 중지 요청이 있으면 재실행하지 않으며 감시 잠금으로 중복 실행을 막습니다. 예측 계산 중 중지가 들어온 경우 새 신호와 계좌 재조정을 발행하지 않는 경계도 추가했습니다. 최초 장치 오류의 하드웨어 원인을 확정한 것은 아닙니다.

실제 추가·수정·삭제 파일, 사소한 공백·주석 변경, 바이너리 크기·해시는 [전체 비교](docs/3차%20전체%20비교.md)에 기록합니다. 모델·데이터·계좌·운영/검증 기록은 비공개입니다. 검사 성공은 투자 수익 우위 또는 실거래 검증 완료를 의미하지 않습니다.

# 6차 · 운영 예측과 추가 학습 분리

추가 학습이 거부되거나 새 학습 날짜가 없을 때도, **마지막으로 채택된 저장 모델이 최신 완결 일봉을 예측**하도록 수정했습니다. 5차의 가중치 보호·학습 예산·고정 검증은 유지합니다.

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

학습은 모델을 고치는 과정이고 예측은 지금의 모델로 다음 값을 계산하는 과정입니다. 학습 결과가 나빠 새 모델을 버리더라도 기존 모델의 예측까지 멈출 필요는 없습니다. 이번 차수에서는 이 두 과정을 나눕니다.

| 과정 | 5차의 동작 | 6차의 동작 |
| --- | --- | --- |
| 추가 학습 거부 | 새 전망 발행도 생략 | 채택 저장본의 운영 예측을 학습 전에 실행 |
| 새 학습 날짜 없음 | 수집·기존 주문 처리만 지속 | 새 예측 입력이면 채택 저장본으로 예측 |
| 같은 입력 재확인 | 새 학습 예약 없음 | 저장본·문맥·자료 해시가 같으면 모델 재로드 생략 |
| 연속 실행 최초 수집 | PC 가동 시간이 수집 주기보다 짧으면 생략 가능 | 첫 루프는 수집하고 이후 6시간 간격 적용 |
| 중지·저장본 손상 | 가중치 보호 | 예측 경로도 STOP·SHA-256 확인 |

| 조건 | 처리 | 확인할 근거 |
| --- | --- | --- |
| 사용 가중치 | 채택된 latest 저장본만 사용 | 파일별 SHA-256 |
| 새 자료 없음 | 학습 예산을 늘리지 않음 | 5차 예약 원장 보존 |
| 같은 예측 입력 | 예측 로드를 생략 | 운영예측_6차.json 완료 해시 |
| 예측 오류·중지 | 완료 해시 미기록 | 다음 확인에서 재시도, STOP이면 발행 차단 |
| 실제 주문 | 연결하지 않음 | 로컬 모의계좌만 처리 |

**거래·수익·과적합 부재를 보장하지 않습니다.** 기존 15개 ETF의 비용·현금·정규장·관측 신선도·중복 체결 방어를 유지합니다. 같은 날짜의 배분은 최초 신호만 사용합니다. 종목별 마지막 일봉 날짜가 다르면 기존 정책에서 가장 이른 날짜를 신호 기준으로 사용하므로 일부 종목 갱신만으로 새 배분이 발행되지 않을 수 있습니다. 날짜가 서로 다른 전망의 효과는 별도 독립 성과로 입증되지 않았습니다.

예측 원장·신호·계좌·완료 기록은 하나의 트랜잭션이 아닙니다. 중간 실패 시 기존 날짜별 중복 신호와 체결 방어를 사용해 재시도하지만, STOP 파일과 발행 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다.

예측 원장·신호·계좌·완료 기록은 하나의 트랜잭션이 아닙니다. 중간 실패 시 기존 날짜별 중복 신호와 체결 방어를 사용해 재시도하지만, STOP 파일과 발행 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다.

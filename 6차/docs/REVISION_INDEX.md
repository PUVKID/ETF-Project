# 전체 차수와 현재 운용

**현재 기준:** 실험·운용 프로젝트는 6차입니다. 디자인 7차의 최신 Astryx 화면을 6차/web에 실제 교체했으며 기본 주소는 http://127.0.0.1:8879/ 입니다. 7차 화면 서버는 이전 디자인 검토 이력이며 기본 실행 경로가 아닙니다.

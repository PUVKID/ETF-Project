# ETF Project · 6차

**현재 상태:** 6차는 추가 학습 채택 여부와 운영 예측을 분리했습니다. 격리된 기존 코드 검사 87개와 최초 수집 조건을 보완한 영향 검사 5개가 통과했습니다. 새 일봉과 채택 저장본으로 예측하며, 실제 주문은 연결하지 않습니다. 과적합 부재·수익 우위는 입증되지 않았습니다.

[LEVEL 1 - Beginner](../docs/읽기안내/레벨1.md) · [LEVEL 2 - Explorer](../docs/읽기안내/레벨2.md) · [LEVEL 3 - Practitioner](../docs/읽기안내/레벨3.md) · [LEVEL 4 - Advanced](../docs/읽기안내/레벨4.md) · [LEVEL 5 - Expert](../docs/읽기안내/레벨5.md)

추가 학습이 거부되거나 새 학습 날짜가 없을 때도, **마지막으로 채택된 저장 모델이 최신 완결 일봉을 예측**하도록 수정했습니다. 5차의 가중치 보호·학습 예산·고정 검증은 유지합니다.

| 과정 | 5차의 동작 | 6차의 동작 |
| --- | --- | --- |
| 추가 학습 거부 | 새 전망 발행도 생략 | 채택 저장본의 운영 예측을 학습 전에 실행 |
| 새 학습 날짜 없음 | 수집·기존 주문 처리만 지속 | 새 예측 입력이면 채택 저장본으로 예측 |
| 같은 입력 재확인 | 새 학습 예약 없음 | 저장본·문맥·자료 해시가 같으면 모델 재로드 생략 |
| 연속 실행 최초 수집 | PC 가동 시간이 수집 주기보다 짧으면 생략 가능 | 첫 루프는 수집하고 이후 6시간 간격 적용 |
| 중지·저장본 손상 | 가중치 보호 | 예측 경로도 STOP·SHA-256 확인 |

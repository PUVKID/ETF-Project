| 과정 | 5차의 동작 | 6차의 동작 |

## 디자인 7차를 운용 6차에 통합

**현재 기준:** 실험·운용 프로젝트는 6차입니다. 디자인 7차의 최신 Astryx 화면을 6차/web에 실제 교체했으며 기본 주소는 http://127.0.0.1:8879/ 입니다. 7차 화면 서버는 이전 디자인 검토 이력이며 기본 실행 경로가 아닙니다.

| 구분 | 통합 후 동작 |
| --- | --- |
| 실행 | 최종/대시보드 실행.cmd → 6차/server.py → 8879 |
| 화면 | 6차/web의 Astryx CSS·Rust 생성 테마·44px 조작부·라이트/다크 |
| 상태·작업 요청 | 같은 6차 서버의 기존 API로 직접 연결, 7차 프록시 의존 없음 |
| 데이터·모델 | 기존 1차 실행 환경·비공개 계좌·체크포인트 유지 |
| 실행 중인 작업 | 화면 교체를 위해 서버·학습을 중단하거나 재시작하지 않음 |
| 검사 | 동일 화면의 기존 독립 검사 재사용, 6차 제공 파일·실행 연결만 추가 확인 |

구 화면은 활성 화면에서 교체했으며 비공개 변경 이력으로만 보존했습니다. 이전 실험·원문 비교·검사 이력은 유지합니다. 화면 통합은 예측 성능·수익 개선을 입증하지 않습니다.

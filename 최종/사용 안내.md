## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

| 구분 | 동작·조건과 확인 범위 |
| --- | --- |
| 시작 파일·환경 연결 | 시작 파일로 대시보드를 열면 3차 코드가 1차 실행 환경·가상 원장·마지막 Chronos-2 가중치를 이어 씁니다. |
| 창 닫기·운용 중지 | 창을 닫는 것은 학습 중지가 아니므로 멈출 때는 운용 중지를 누릅니다. |
| 가상 원금·계좌 범위 | 원금은 가상 원화 100만 원이며 실제 계좌는 연결하지 않습니다. |
| 비용 가정의 한계 | 수수료 기본 0.1%와 환전·SEC 비용 가정은 실제 토스 전체 비용과 다릅니다. |
| 보유·거래·대기 구분 | 보유·거래·환전과 대기 상태를 따로 보고 체결이 없으면 0건으로 읽습니다. |
| 학습·매매 독립성 | 학습을 계속해도 매번 매매할 필요는 없습니다. |


### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

| 구분 | 동작·조건과 확인 범위 |
| --- | --- |
| 대시보드 시작 | `최종/대시보드 실행.cmd`를 실행하고 [대시보드](http://127.0.0.1:8879/)를 엽니다. |
| 코드·환경·원장 계승 | 3차 코드가 1차의 전용 실행 환경·모의 원장·마지막 Chronos-2 가중치를 이어 사용합니다. |
| 함께 보존할 폴더 | 1차와 3차 폴더를 함께 보존하세요. |
| 이전 화면 이력 | 이전 2차 화면과 문서는 이력으로 남깁니다. |
| 연속 학습 실행 조건 | PC가 켜져 있고 학습 프로세스가 실행 중일 때 같은 모델을 계속 추가 학습합니다. |
| 창 닫기·학습 중지 | 창을 닫는 것과 학습 중지는 다릅니다. |
| 운용 중지 버튼 | 학습을 멈추려면 화면의 ‘운용 중지’를 누르세요. |
| PC·네트워크 중단 한계 | 전원 종료·절전·인터넷 중단 중에는 정상 운용을 보장하지 않습니다. |
| 치명 CUDA 복구 | 학습 감시 프로세스는 확인된 치명 CUDA 오류가 발생하면 마지막 저장 가중치로 새 학습 프로세스를 실행합니다. |
| 복구 표시·사용자 중지 | 화면에 복구 대기와 재실행 상태를 표시하고, 사용자 중지 뒤에는 재시작하지 않습니다. |
| 자동 복구의 한계 | 전원 종료나 모든 종류의 하드웨어 오류까지 자동 복구하는 기능은 아닙니다. |
| 모의 원금 | 모의 원금은 원화 100만 원입니다. |
| 기존 환전·현금 계승 | 달러로 환전한 기존 현금과 환전 기록을 그대로 사용합니다. |
| 실제 계좌 미연결 | 사용자의 실제 보유와 토스 계좌는 연결하지 않습니다. |
| 기본 비용·실제 거래 차이 | 기본 매매 수수료 0.1%, 공개 기본 환전·SEC 비용 가정이며 실제 토스의 호가·환율·배당 지급 일·세금·결제 전체와 같지는 않습니다. |
| 비용 정책 재확인 시점 | 비용 정책은 2027년 전환 전에 다시 확인해야 합니다. |
| 보유·손익 확인 | ‘보유·거래’에서 현재 보유 종목·수량·평균 매입가·원화 원가·평가·손익을 확인합니다. |
| 주문·체결·환전 구분 | 주문 대기와 실제 모의 체결을 구분하며 환전은 별도 표에 표시합니다. |
| 거래 페이지·필터 | ETF 거래 내역은 매수·매도 필터와 페이지 이동으로 전체 기록을 읽습니다. |
| 미체결 표시 | 아직 체결이 없으면 보유와 거래는 0건으로 표시됩니다. |
| 자동 선택 후보 목록 | 자동 매매 후보는 QQQM·SCHG·SPYM·VTI·VEA·VWO·BND·IEF·TLT·SGOV·GLD·XLK·XLF·XLV·XLE입니다. |
| 후보 선택 조건 | 모델 예측·비용·현금 제약으로 선택합니다. |
| 후보 검증 범위 | 모든 상장 ETF 또는 토스 지원 전 종목을 검증한 목록은 아닙니다. |
| 제외한 투자 방식 | 차입·공매도·레버리지 ETF는 사용하지 않습니다. |
| 학습·거래 독립성 | 학습을 계속해도 매번 거래할 필요는 없습니다. |
| 학습 입력 자료 | 학습 자료는 무료 완결 일봉입니다. |
| 모의체결 입력·지연 | 실제 운용의 모의 체결에는 주문 뒤 시작한 정규 장 완결 1분봉을 사용하며 최대 20분 지연을 허용합니다. |
| 시장 시간·가격 대기 | 현재 정규 장이어야 하고 시세가 없거나 오래됐으면 개별 주문을 대기합니다. |
| 소급 체결 거부 | 과거 시가로 소급 체결하지 않습니다. |
| 상태 조회·시세 구분 | 화면의 1초 상태 확인은 무료 초 단위 실시간 시세를 뜻하지 않습니다. |
| 백분율·원값 확인 | 백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율과 전체 정밀도는 원값 보기에서 확인합니다. |
| 원값 스냅샷 갱신 | 원값 스냅샷은 직접 갱신하고 저장 결과는 바꾸지 않습니다. |
| 반올림 만점의 의미 | 반올림된 100.0%와 실제 원비율 1을 구분합니다. |
| 과거 비교·현재 수익 | 과거 비교 수익과 가정 시나리오는 현재 모의 계좌 수익과 다릅니다. |
| 수익·실거래 검증 한계 | 수익 우위나 실거래 검증 완료를 의미하지 않습니다. |
| 화면 조작 지원 | 키보드 메뉴·버튼·입력 이동, 표 가로 스크롤, 다크·라이트와 화면 모션 정지·재생을 제공합니다. |
| 미검증 화면 조합 | 전체 마우스 오버·200% 확대·운영체제 모션 축소·전체 터치 조합은 미검증 범위입니다. |
| GitHub 공개 범위 | 프로그램·일반 문서만 GitHub에 공개합니다. |
| 로컬 비공개 자료 | 시세 원본·학습 가중치·모의 원장·인증 정보·개인 지침은 로컬에 보관합니다. |

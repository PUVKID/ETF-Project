# 📈 ETF Project

10년 이상 장기투자를 위한 로컬 학습·모의운용 도구입니다. 사전학습 시계열 모델을 추가 학습하고, 단순 보유와 비교하며, 데이터 수집부터 검증까지의 실제 진행 상태를 대시보드에 표시합니다.

약 두 달간의 연속 학습을 계획하고, 가상계좌 원금 100만 원을 달러로 환전하여 ETF 모의투자를 진행합니다. 평가·손익·비용은 원화로 표시하고 원화·달러 현금을 구분합니다. 기존 실제 계좌 보유 내역은 사용하지 않습니다. 같은 모델의 가중치를 계속 갱신하며, 구조를 무조건 확대하거나 모델 후보를 반복 채택하지 않습니다.

**기술 분류:** 시계열 예측 · 추가 학습 · 장기투자 모의운용 · 로컬 대시보드

## ▶️ 실행

이 컴퓨터에서는 `1차`의 전용 실행 환경을 사용합니다. 서버가 켜져 있으면 [대시보드](http://127.0.0.1:8879/)를 열고, 꺼져 있으면 같은 프로젝트 `최종` 폴더의 `대시보드 실행.cmd`를 실행합니다. [사용 안내](2차/사용%20안내.md)에 중지·재개 방법과 비용 재현 범위를 정리했습니다. 가중치와 전용 환경은 공개 코드에 포함하지 않습니다.

## 🔎 운용 방식

무료 일봉 데이터를 수집하고 사전학습 모델 `amazon/chronos-2` 하나를 마지막 저장 가중치에서 계속 이어서 학습합니다. 회차마다 모델을 경쟁시키거나 채택하는 절차는 없습니다. 학습·검증·시험 구간을 시간순으로 분리하고 예측 오차는 상태 관찰용 기록으로 남깁니다. 모델의 일반 시계열 성능이 투자 수익 우위를 뜻하지 않으므로 단순 보유 성과도 참고합니다.

상시 운용은 로컬 프로세스가 실행되는 동안 수집·학습·상태 평가·모의운용을 반복하는 방식입니다. 화면의 1초 갱신은 무료 시세가 매초 바뀐다는 뜻이 아닙니다. 신규 데이터가 없는 반복 학습과 새 데이터 학습을 구분하고, 누적 학습과 마지막 저장 시각을 표시합니다. 전원·인터넷·프로세스가 중단되면 운용도 중단됩니다.

## 🔐 비공개 자료

시세 원본, 모델 가중치, 계좌 정보, 키, 운영 기록은 공개 코드에서 제외합니다. 대시보드는 로컬에서 실행하며 토스 계좌의 실제 주문을 전송하지 않습니다. 실제 계좌 손익을 표시하지 않고 모의 원금 대비 손익만 계산합니다.

## 📐 성과를 읽는 기준

- 과거 모의 성과, 운용 시작 후 실제로 쌓이는 전진 모의 기록, 가정 수익률 시나리오를 구분합니다.
- 추가 학습 손실이 낮아져도 실제 투자 수익 개선이 입증되는 것은 아닙니다.
- 동일 시험 구간의 반복 평가와 사전학습 데이터의 시점 불확실성을 공개합니다.
- 10년은 계획 기간입니다. QQQM 자체의 10년 과거 이력이 없으므로 해당 성과를 만들어 표시하지 않습니다.
- 환율·세금·실거래 호가와 체결 차이는 남습니다. 수익과 원금 보존을 보장하지 않습니다.

논문·원고는 없는 소프트웨어 프로젝트입니다. PDF 논문은 포함하지 않습니다.

## 🧪 확인 결과와 반영 상태

핵심 단위검사와 JavaScript 문법 검사를 구현자와 별도 검토자가 각각 수행합니다. 최초 20단계 가중치 저장과 다음 회차에서 해당 가중치의 이어 학습·누적 단계 증가를 실제 확인했습니다. 초기 시험 MAPE는 추가 학습 0.76%(둘째 자리 아래 버림), 무변화 예측 0.75%(둘째 자리 아래 버림)로 투자 우위를 입증하지 않았습니다. 최종 상시 관측에서 발견한 Windows 상태 저장 충돌은 실제 읽기 핸들로 재현하여 제한된 원자 교체 재시도와 영구 실패 검사를 추가했습니다.

무료 시세와 토스 일반 공시 비용을 사용하는 모의운용이며 세후 실계좌 재현은 아닙니다. 1차 공개 파일 38개의 원격 커밋·전체 tree·주요 HTTP 원문 일치를 확인했습니다. 2차는 수치 표시 46개 검사와 서버 경계 6개 검사를 포함하며, 각 묶음의 독립 검토와 원격 검증 기록은 로컬에 별도로 보존합니다.

## 🔢 수치 표시와 원값

백분율 요약은 소수 둘째 자리 아래를 버립니다. 다른 요약도 표시 자릿수 아래를 버리며, 저장된 원비율과 전체 정밀도는 화면의 원값 보기에서 확인합니다. 원값 스냅샷은 자동 갱신 중 고정되며 직접 갱신합니다. 데이터 파일은 표시 목적으로 바꾸지 않습니다. 작은 화면의 테마 버튼과 검증 표 키보드 포커스를 보완했습니다.

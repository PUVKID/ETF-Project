# ETF Project

**현재 상태:** 5차 준비 본의 코드 검사 83개와 화면 표시 검사 85개가 통과했고 최종 의미 검토는 진행 중입니다. 5차 실행 전환은 완료되지 않았으며 최종 실행 자료는 3차를 유지합니다. 5차 GPU 추가 학습은 실행되지 않았고 독립 미래 성과·과적합 완전 방지·수익은 입증되지 않았습니다.


## 5차 공개 안내

[5차를 포함한 전체 차수 목차](5차/docs/REVISION_INDEX.md) · [5차 상세](5차/docs/5차%20상세.md)

**5차는 신규 관측 별 제한 학습과 저장 전 검증을 구현한 변경 본입니다.** 5차 실행 전환은 완료되지 않았고 GPU 추가 학습과 독립 미래 성과·과적합 완전 방지는 입증되지 않았습니다. 아래 4차 문서와 기록은 이전 상태로 보존합니다.

| 조건 | 5차 방어 설계 |
| --- | --- |
| 학습 시점 | 최초 1회와 이후 새로운 학습 적합 관측 날짜가 있을 때 |
| 반복 방지 | 학습 전 예약을 영속 기록해 같은 관측 집합만으로 새 회차 예약·재시작 반복 방지 |
| 학습 설정 | 최대 25 단계, 학습률 0.000001, weight decay 0.01, gradient clipping 1.0 |
| 저장 전 검사 | 최초 세 ETF의 고정 검증 자료에서 전후 MAE·MAPE 악화 0 허용, 유한 값·표본 수 확인 |
| 발행 전 악화·STOP·오류 | 기존 운영 포인터 유지, 새 가중치의 주문 전망 발행 금지 |
| 새 관측 없음 | 학습 대기, 자료 수집과 모의운용은 계속 |

새 날짜는 새 회차를 허용하는 조건입니다. 허용된 회차에서는 전체 허용 학습 자료를 다시 사용하므로 과거 행도 다시 표본으로 뽑힐 수 있습니다. 무작위 표본 방식이므로 매 회차에 모든 신규 행이 학습된다는 보장은 없습니다.

발행 직전에 STOP을 확인하지만 별도 STOP 파일과 포인터 사이의 프로세스 간 완전한 원자성은 보장하지 않습니다. 검증을 통과해 포인터 원자 발행이 끝난 뒤 보고·원장 기록이 실패하면 이미 반영된 검증 가중치를 유지합니다. 예약 파일의 원자 저장만으로 동시 경합을 막지는 않으며 단일 작업자 잠금이 운영 경계입니다.

이 변경은 **같은 Chronos-2의 추가 학습을 보호**하는 설계이며 서로 다른 모델을 경쟁시켜 선택하는 방식이 아닙니다.

고정 검증을 반복해서 확인하면 그 검증 자료에 맞춰질 위험이 남습니다.

세 ETF 기준은 전체 15 종과 환율에 대한 독립 성과를 입증하지 않습니다.

미래 전진 평가는 별도로 유지합니다.

과적합을 완전히 막거나 이미 과적합된 모델을 자동 치료한다고 보장하지 않으며 수익도 보장하지 않습니다.

## 실행

5차 준비 본은 1차 전용 환경·비공개 저장소를 사용하도록 구성했습니다. 5차 실행 전환은 완료되지 않았습니다. 공개 코드에는 가중치와 실행 환경을 포함하지 않습니다.

- 서버가 켜져 있으면 [대시보드](http://127.0.0.1:8879/)를 엽니다.
- 서버가 꺼져 있으면 프로젝트 최종 폴더의 `대시보드 실행.cmd`를 실행합니다.

<a name="-보유와-거래"></a>
## 보유와 거래

화면은 현재 보유 ETF·수량·평균 매입가·원화 원가와 평가·미실현 손익을 보여 줍니다. 대기 주문과 체결 내역을 구분하고 체결 내역은 매수·매도 필터와 페이지 이동으로 전체 기록을 읽습니다. 환전은 별도 내역입니다. 새 관측을 확보하기 전에는 거래가 0건일 수 있습니다.

후보는 QQQM·SCHG·SPYM·VTI·VEA·VWO·BND·IEF·TLT·SGOV·GLD·XLK·XLF·XLV·XLE입니다. 모델 예측과 비용·현금 제약으로 자동 선택합니다. 모든 ETF 또는 토스 지원 전 종목을 검증한 목록은 아닙니다. 차입·공매도·레버리지 ETF는 사용하지 않습니다.

학습용 완결 일봉과 체결용 정규 장 완결 1분봉을 구분합니다. 주문 뒤 시작한 봉, 현재 정규 장, 최대 20분 지연 조건을 충족해야 모의 체결합니다. 과거·장외·미래·오래된 관 측은 체결로 만들지 않습니다. 무료 데이터 부재는 대기로 표시합니다. 화면의 1초 상태 갱신은 실시간 초 단위 시세를 뜻하지 않습니다.

<a name="-이어-학습과-성과-해석"></a>
## 이어 학습과 성과 해석

`amazon/chronos-2`의 같은 마지막 가중치를 계속 갱신합니다.

회차마다 모델을 경쟁시키거나 채택하지 않습니다.

최초 세 ETF의 고정 평가 원본과 조정 값을 우선 보존합니다. 4차는 15개 ETF와 KRW =X의 수집 가능한 전체 일봉을 요청하고, 2024-06-03 이하와 2026-11-06 이후를 별도 시계열로 학습합니다.

검증 2024-06-04~2025-08-21과 시험 2025-08-22~2026-11-06은 모든 자산의 학습에서 제외합니다.

환율은 독립 단 변 량이며 ETF 공 변 량이나 인과 학습이 아닙니다.

시험 종료 뒤 추가 학습은 독립 시험 성과가 아닙니다.

실제 제공 기간과 짧은 구간의 학습 적합 여부는 실행 결과로 확인해야 합니다.

약 두 달 학습은 운용 계획입니다. PC와 로컬 프로세스 실행 중 반복하며 전원·절전·인터넷·프로세스 중단의 영향을 받습니다. 같은 표본의 반복 횟수와 독립 원본 수를 구분합니다.

초기 20 단계 시험 MAPE 원값은 추가 학습 약 0.7643%, 무변화 예측 약 0.7550%였으며 요약은 각각 0.8%, 0.8%입니다. 투자 수익 우위가 입증된 결과는 아닙니다.

과거 모의 비교, 운용 후 쌓이는 전진 기록, 가정 수익률 시나리오는 다릅니다. 사전 학습 데이터의 개별 자산·시점 경계는 확인되지 않았습니다. 10년은 계획 기간이며 짧은 ETF 이력을 10년 실측 성과로 만들지 않습니다. 수익·원금 보존·실거래 성능을 보장하지 않습니다.

<a name="-수치와-원값"></a>
## 수치와 원값

백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율·전체 정밀도를 펼쳐 확인합니다. 반올림된 100.0%와 실제 모든 정답을 구분합니다. 원값 스냅샷은 직접 갱신하고 원본 결과를 표시 목적으로 바꾸지 않습니다. 1·2차의 이전 표시 방식은 역사적 문서에 보존합니다.

<a name="-비용과-공개-범위"></a>
## 비용과 공개 범위

토스 기본 매매 수수료 0.1%와 공개 기본 환전·SEC 비용 가정을 반영합니다. 실제 거래 가능 종목·호가·결제·배당 지급일·환율·세금 전체와 같지는 않습니다. 실제 토스 주문을 전송하지 않습니다. 시세 원본·가중치·모의 원장·인증정보·개인 지침·운영 기록은 공개에서 제외합니다.

논문·원고가 없는 소프트웨어 프로젝트입니다. 단위·표시·API 경계 검사와 별도 검토를 수행하며, 공개 반영은 현재 원격 커밋·전체 tree·주요 HTTP 원문과 차수 링크로 확인합니다. 과거 실패와 미검증 UI 범위는 별도 로컬 기록에 남깁니다.

# ETF Project

10년 이상 장기투자를 위한 로컬 학습·모의운용 도구입니다. 사전학습 시계열 모델 Chronos-2 하나의 마지막 가중치를 계속 추가 학습하고, 원화 100만 원을 달러로 환전한 가상계좌에서 ETF를 자동 선택·매매합니다. 실제 보유와 토스 계좌는 연결하지 않습니다.

## 실행

이 컴퓨터에서는 3차 서버·엔진과 1차 전용 환경·비공개 저장소를 함께 사용합니다. 공개 코드에는 가중치와 실행 환경을 포함하지 않습니다.

- 서버가 켜져 있으면 [대시보드](http://127.0.0.1:8879/)를 엽니다.
- 서버가 꺼져 있으면 프로젝트 최종 폴더의 `대시보드 실행.cmd`를 실행합니다.
- 중지·재개와 비용 재현 범위는 [사용 안내](3차/사용%20안내.md)에서 확인합니다.

<a name="-보유와-거래"></a>
## 보유와 거래

화면은 현재 보유 ETF·수량·평균 매입가·원화 원가와 평가·미실현손익을 보여 줍니다. 대기 주문과 체결 내역을 구분하고 체결 내역은 매수·매도 필터와 페이지 이동으로 전체 기록을 읽습니다. 환전은 별도 내역입니다. 새 관측을 확보하기 전에는 거래가 0건일 수 있습니다.

후보는 QQQM·SCHG·SPYM·VTI·VEA·VWO·BND·IEF·TLT·SGOV·GLD·XLK·XLF·XLV·XLE입니다. 모델 예측과 비용·현금 제약으로 자동 선택합니다. 모든 ETF 또는 토스 지원 전 종목을 검증한 목록은 아닙니다. 차입·공매도·레버리지 ETF는 사용하지 않습니다.

학습용 완결 일봉과 체결용 정규장 완결 1분봉을 구분합니다. 주문 뒤 시작한 봉, 현재 정규장, 최대 20분 지연 조건을 충족해야 모의 체결합니다. 과거·장외·미래·오래된 관측은 체결로 만들지 않습니다. 무료 데이터 부재는 대기로 표시합니다. 화면의 1초 상태 갱신은 실시간 초 단위 시세를 뜻하지 않습니다.

<a name="-이어-학습과-성과-해석"></a>
## 이어 학습과 성과 해석

`amazon/chronos-2`의 같은 마지막 가중치를 계속 갱신합니다. 회차마다 모델을 경쟁시키거나 채택하지 않습니다. 최초 세 ETF의 고정 학습·검증·시험 구간과 기준 평가를 보존하고 신규 ETF의 과거 학습은 원래 학습 종료일 이하로 제한합니다. 최초 시험 종료 뒤 새 자료는 추가 학습이며 독립 시험 성과가 아닙니다.

약 두 달 학습은 운용 계획입니다. PC와 로컬 프로세스 실행 중 반복하며 전원·절전·인터넷·프로세스 중단의 영향을 받습니다. 같은 표본의 반복 횟수와 독립 원본 수를 구분합니다.

초기 20단계 시험 MAPE 원값은 추가 학습 약 0.7643%, 무변화 예측 약 0.7550%였으며 요약은 각각 0.8%, 0.8%입니다. 투자 수익 우위가 입증된 결과는 아닙니다.

과거 모의 비교, 운용 후 쌓이는 전진 기록, 가정 수익률 시나리오는 다릅니다. 사전학습 데이터의 개별 자산·시점 경계는 확인되지 않았습니다. 10년은 계획 기간이며 짧은 ETF 이력을 10년 실측 성과로 만들지 않습니다. 수익·원금 보존·실거래 성능을 보장하지 않습니다.

<a name="-수치와-원값"></a>
## 수치와 원값

백분율 요약은 소수 첫째 자리로 반올림하며 저장 원비율·전체 정밀도를 펼쳐 확인합니다. 반올림된 100.0%와 실제 모든 정답을 구분합니다. 원값 스냅샷은 직접 갱신하고 원본 결과를 표시 목적으로 바꾸지 않습니다. 1·2차의 이전 표시 방식은 역사적 문서에 보존합니다.

<a name="-비용과-공개-범위"></a>
## 비용과 공개 범위

토스 기본 매매 수수료 0.1%와 공개 기본 환전·SEC 비용 가정을 반영합니다. 실제 거래 가능 종목·호가·결제·배당 지급일·환율·세금 전체와 같지는 않습니다. 실제 토스 주문을 전송하지 않습니다. 시세 원본·가중치·모의 원장·인증정보·개인 지침·운영 기록은 공개에서 제외합니다.

논문·원고가 없는 소프트웨어 프로젝트입니다. 단위·표시·API 경계 검사와 별도 검토를 수행하며, 공개 반영은 현재 원격 커밋·전체 tree·주요 HTTP 원문과 차수 링크로 확인합니다. 과거 실패와 미검증 UI 범위는 별도 로컬 기록에 남깁니다.

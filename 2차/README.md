# 관측값을 확인하는 장기투자 대시보드

1차의 Chronos-2 이어 학습과 원화 100만 원 모의 원장을 유지하면서 수치 표시와 화면 조작을 보완했습니다. 백분율 요약은 소수 둘째 자리 아래를 버리며, 원비율과 전체 정밀도는 ‘저장 원값 보기’에서 확인합니다. 화면의 요약 표시 때문에 원본 결과를 고치지 않습니다.

2차 서버는 `../1차/src`의 기존 엔진을 사용하며, 가중치·원장·환경도 1차에 그대로 보관합니다. 2차는 화면과 서버 진입점의 후속 차수이며 새 모델 학습 실험을 뜻하지 않습니다.

## 실행

프로젝트 전체 폴더 구조를 유지한 상태에서 [최종 실행 파일](../최종/대시보드%20실행.cmd)을 실행합니다. 기존 학습 작업이 실행 중이면 중복 학습을 시작하지 않습니다. 같은 포트의 기존 서버가 있으면 실행 전에 현재 서버를 확인해야 합니다.

## 바뀐 동작

- 백분율과 표시 자릿수를 십진 표현에서 잘라 표시하고, 원값 스냅샷을 사용자가 직접 갱신합니다.
- 작은 화면에서도 테마를 전환하고 검증 표에 키보드로 접근할 수 있도록 보완합니다.
- loopback·출처 검사·비공개 파일 차단·실주문 경로 없음 경계는 유지합니다.

투자수익 우위나 모든 미래 결함의 부재를 주장하지 않습니다. 무료 일봉은 실시간 호가가 아니며, 반복한 같은 표본은 새로운 독립 표본이 아닙니다. 실제 토스 주문은 연결하지 않습니다.

## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

이 차수는 모델을 다시 학습한 것이 아니라 숫자와 조작을 보여 주는 화면을 고쳤습니다. 당시 규칙은 백분율을 소수 둘째 자리 아래에서 버리는 것이며 저장한 원비율은 원값 보기로 그대로 확인합니다. 원값은 사용자가 갱신하는 스냅샷이라 읽는 중 자동으로 값이 바뀌지 않습니다. 모바일 테마 버튼을 드러내고 표에 키보드 포커스를 주었습니다. 2차 화면 서버를 쓰더라도 학습·잠금·원장·체크포인트는 1차 경로를 이어 사용하므로 화면 교체가 학습 종료를 뜻하지 않습니다.

### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

사용자 수치 표시 지침을 반영한 화면 후속 차수입니다. 기존 1차의 백분율 요약은 `toLocaleString`의 반올림을 사용했습니다. 이제 소수 둘째 자리 아래를 버리고 저장된 원비율·전체 정밀도를 원값 보기로 확인하도록 바꿉니다. 데이터·학습 결과 파일과 모델 가중치는 변경하지 않습니다.

모바일 테마 전환의 노출을 명확히 하고, 검증 표의 스크롤 영역에 키보드 포커스를 제공합니다. 원값 영역은 사용자가 스냅샷을 갱신하는 방식으로 자동 갱신 중 읽던 값이 바뀌지 않게 합니다.

2차 서버는 1차 서버에서 진입점을 복사한 뒤 화면 경로를 2차로 고정합니다. 엔진 모듈 경로는 형제 폴더 1차로 명시하며 학습 프로세스의 작업 경로·잠금·원장·체크포인트는 유지합니다. 화면 서버를 교체해도 실행 중인 별도 학습 작업을 종료하지 않습니다.

독립 검증에서는 표시 경계값·음수·지수 표기, 원값 보존, 입력 없음, 서버의 비공개 파일 및 실제 주문 차단을 확인합니다. 실제 실행 결과와 확인하지 못한 조작은 별도 검증 기록에 구분합니다.

## LEVEL 2 - Explorer

### LEVEL 2 · 구성과 조건의 관계

표시 형식과 저장 결과를 나눕니다. 1차의 반올림에서 2차의 소수 둘째 자리 버림으로 바뀌지만 원비율·가중치·결과 파일은 그대로입니다. 사용자가 갱신하는 원값 스냅샷은 자동 화면 갱신과 별개이며 테마 노출·표 키보드 이동도 표시 영역의 변경입니다. 서버 진입점은 2차 화면으로 고정하고 엔진은 형제 1차 폴더를 가리켜 기존 작업을 이어갑니다.

## LEVEL 3 - Practitioner

## LEVEL 4 - Advanced

### LEVEL 4 · 설계·평가·실패 경계

표시 계층만 바꿔 데이터·모델 계보를 유지한 차수입니다. 소수 둘째 자리 버림과 수동 원값 스냅샷은 저장값 불변성과 읽기 안정성의 서로 다른 계약입니다. 2차 서버의 고정 화면 경로와 1차 엔진 참조를 명시해 프로세스·잠금·원장·체크포인트의 동일성을 유지합니다. 경계값·음수·지수 표기·입력 없음·실제 주문 차단의 검증 범위를 후속 표시 규칙과 혼합하지 않습니다.

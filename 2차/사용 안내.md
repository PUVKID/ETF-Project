`최종/대시보드 실행.cmd`를 실행하고 [대시보드](http://127.0.0.1:8879/)를 엽니다. 2차 서버가 2차 화면을 제공하며, 1차의 실행 환경·학습 엔진·가중치·원장은 그대로 이어 사용합니다. 두 차수 폴더를 함께 보존하세요.

PC가 켜져 있고 학습 프로세스가 실행 중일 때 계속 학습합니다. 창을 닫는 것과 학습 중지는 다릅니다. 학습을 멈추려면 화면의 ‘운용 중지’를 누르세요. 전원이 꺼진 동안에는 실행되지 않습니다.

모의 원금은 원화 100만 원입니다. 달러로 환전한 모의 현금으로 ETF를 매매하며 평가·손익·비용은 원화로 표시합니다. 사용자의 실제 보유와 계좌는 연결하지 않습니다. 기본 매매 수수료 0.1%, 공개 기본 환전·SEC 비용 가정을 반영하며 실제 토스 호가·환율·배당 지급일·세금·결제 전체와 완전히 같지는 않습니다. 비용 정책은 변경될 수 있으므로 2027년 전환 전에 다시 확인해야 합니다.

무료 시세는 일봉입니다. 화면의 1초 상태 확인이 초 단위 거래 가능한 시세를 뜻하지 않습니다. 새 완결 일봉이 없으면 같은 학습 표본을 다시 사용하며 반복 횟수와 독립 표본 수를 구분합니다. 새 신호 이후의 미래 거래일 시가가 관측되기 전에는 체결을 만들지 않습니다.

수치 요약은 표시 자릿수 아래를 버립니다. 백분율은 소수 둘째 자리까지이며 ‘저장 원값 보기’에서 원비율과 전체 정밀도를 확인합니다. 원값 스냅샷은 직접 갱신하며 저장 결과를 바꾸지 않습니다. 과거 비교 수익률과 가정 시나리오는 현재 모의계좌 수익과 구분합니다. 수익 우위가 입증된 상태나 실거래용 검증 완료로 해석하지 마세요.

키보드로 메뉴·버튼·입력을 이동할 수 있으며 검증 표는 스크롤 영역에 포커스를 둔 뒤 가로로 이동합니다. 다크·라이트 테마와 화면 모션 정지·재생을 지원합니다. 브라우저 확대·운영체제 모션 축소와 전체 터치 조합은 확인 범위가 제한되어 있습니다.

프로그램·문서만 GitHub에 공개하며 시세 원본·학습 가중치·모의 원장·인증정보·개인 지침은 로컬에 보관합니다.
